# 学层精讲合同（physics-hkj-yj · 沪科技粤教版初中物理）

## 你的任务
分片 JSON 的 `lessons[]` 给了 1–3 个课时点，为**每一个点**写一篇学生自己能读懂的精讲，
每篇单独落盘到它自己的 `out` 路径（`learn/_parts/<册>/<topicId>.json`），形状：
`{"book": "<册>", "lessons": [{"topicId","title","markdown","words"}]}`。

## 七节（标题逐字、顺序固定）
1. `## 一、开场` —— 从学生见过的现象或实验室场景切入，一两句把本课要解决的问题摆出来。
2. `## 二、课本原文` —— **至少 2 处** `> ` 块引用，**逐字抄本册教材**（每处 ≥8 汉字），
   每处后紧跟「这句话的意思是……」；引文必须能在分片给的 `excerpt`（本课教材节选）里逐字命中，
   ⛔ 不许改写、不许拼接、不许凭印象编。excerpt 里没有的句子不要用。
3. `## 三、费曼翻译` —— 「假设你要给同桌讲明白」的口吻，把概念翻成大白话＋一个生活类比。
4. `## 四、例题精讲` —— **2 道**（「例 1」「例 2」），每道按「审题 → 第一步 → 第二步 → 答案 → 回头看」写，
   每道至少一处 `❌ 常见错法` 与 `✅ 正确做法`；例题用分片 `bank_samples` 的同型变式，计算**自己复算**并核对单位。
5. `## 五、易错点拨` —— 至少 2 条，每条写「错在哪 → 为什么错 → 怎么防」。
6. `## 六、五步学习法` —— 5 条，条与条之间空一行，顺序固定、结合本课具体化：
   ①每天锻炼一个小时 ②扎实掌握第一个知识点 ③能积微者速成 ④运用对标思维突破学习困境 ⑤运用杠铃法则缓解学习疲劳。
   **每条 65–120 汉字**（五条合计 ≥350）。
7. `## 七、方法锚与自查` —— 一句加粗「方法锚」＋ `- [ ]` 自查题 ≥3 条。

## 硬指标（checker 逐条断言）
- 全篇汉字 **1200–2800**；「六、五步学习法」节 **350–900** 汉字；`words` = 实测汉字数。
- 例题 ≥2 道、「❌」「✅」各 ≥2 处；七节标题齐全有序；自查 ≥3 条。
- 禁 LaTeX、HTML、Markdown 表格竖线、「如图／下图」指代。
- 禁教师语域与套话：教学目标、考点、命题趋势、首先、其次、综上所述、总而言之、由此可见、赋能、抓手、闭环、值得注意的是。
- 只讲本课时，不提前教后面课时的解法。

## 自检（必须跑到 PASS）
```bash
python3 scripts/check_chem_editions_learn.py --bucket physics-hkj-yj --file <你做的那篇 json>
```
⛔ 不许改 checker；只写自己的 out，不动 topics/questions/别人分片。

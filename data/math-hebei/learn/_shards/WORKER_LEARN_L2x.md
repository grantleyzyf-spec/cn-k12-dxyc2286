## 1 七段结构（标题逐字，序号名称都不要改）

```
## 一、先说生活里的一件事
## 二、课本原文说了什么
## 三、把它说得更简单
## 四、例题走一遍
## 五、容易错在哪
## 六、五步学习法
## 七、一句话记住，外加自查
```

- **一、生活场景**：用一年级学生真会遇到的事开场（分本子、排路队、买早点、跳绳计数…），自然引出本课要解决的问题。100–250 汉字。
- **二、课本原文**：**≥2 处**引用，写成 `> 课本原句`，每处引用后紧跟一句「这句话的意思是……」解释。引文必须一字不差地从教材原文复制（见 §2）。
- **三、费曼翻译**：把本课的数学道理讲给「没学过的小朋友」听，用类比和生活经验，不用术语堆砌。
- **四、例题走一遍**：**≥2 道**例题，每道都给出 ❌（典型错解，写清错在哪）与 ✅（正解，写清算理）。
- **五、容易错在哪**：2–4 条，写学生真实的错法（把第几当几个、加减混淆、凑十拆错、数位不分…）。
- **六、五步学习法**：五条，标签**逐字**如下（顺序不可变）：
  1. `①每天锻炼一个小时`
  2. `②扎实掌握第一个知识点`
  3. `③能积微者速成`
  4. `④运用对标思维突破学习困境`
  5. `⑤运用杠铃法则缓解学习疲劳`
  每条 **≥25 汉字**，整节 **350–700 汉字**；每条都要结合本课具体内容，不要泛泛谈学习法。
  ⛔ 导语里不要提前出现「五步学习法」四个字（会截断整节）。
- **七、一句话记住 + 自查**：先给一句可背下来的口诀式总结，再列 `- [ ]` 自查 **≥3 条**。

全篇 **1200–2600 汉字**（一年级偏 1200–1800 即可，别注水）。

## 2 课本原文引文的严格纪律（最容易挂的一条）

教材全文在派单的 `txt` 字段（逐页 `===== PAGE n =====`），逐页文件在同目录 `ocr/pNNN.txt`。

- 先按**单元名**在全文里定位（一年级课时名在书上常写成别的字样，如「认识1~5」书上写「认识 1～5」），再顺读相邻页（一课常跨 2–4 页）
- 引文取**页内完整句**，不跨页、不含页码、不含注音符号；长度 ≥8 汉字
- 交付前必须做严格自检：把引文去空白后，**必须**能在教材全文（去空白）里找到。命中率必须 100%，不允许「差不多就算」。宁可换一句短的，也不要改写原文。

## 3 语言纪律

- 学生向、口语化；一年级用短句；不用「综上所述」「众所周知」这类书面套话
- 公式与算式用纯文本：`9+5=14`、`13>9`、`10+3`；不用 LaTeX、不用图片、不用表格、不用 HTML
- ⛔ 不写「扫描件/OCR/抽取/文字层」这类元话语；不写流水线字段
- 一课只讲本课内容；一年级不讲退位减法、不讲乘法口诀

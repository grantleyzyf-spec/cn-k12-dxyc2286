# 北师大版（郭玉英）初中物理 · 试卷讲解合同（28 卷）

## 你要写什么
- 卷面：`data/physics-bsd-gyy/exams/<册>/<卷名>.json`（24 题 / 120 分）
- 落盘：`data/physics-bsd-gyy/exam_lectures/<册>/<卷名>.json`（与卷面同名、同册目录）
- 形状：`{"examId","book","paper","kind","markdown","words"}`（`words` 填实测汉字数）

## 六段标题（逐字照抄，顺序不许变）
```
## 一、这份卷在考什么
## 二、考点地图
## 三、逐题精讲
## 四、整卷复盘
## 五、五步学习法
## 六、自查清单
```

## 硬指标（checker 逐条查）
- 全篇 **4000–7800 汉字**（目标 5000–6000，`words` 必须等于实测值）
- **24 个题号全部讲到**，写法统一 `第 N 题（X 分）`，X 必须等于卷面该题分值
- 逐题四要素：「**思路**」≥22 次、「**关键一步**」≥15 次、「**易错**」≥22 次
- 五步学习法五条**逐字**用这五个标签：`每天锻炼一个小时`、`扎实掌握第一个知识点`、`能积微者速成`、
  `运用对标思维突破学习困境`、`运用杠铃法则缓解学习疲劳`；该节 250–750 汉字
- 自查清单 `- [ ]` ≥6 条（可判定，不写空话）
- ⛔ 禁 Markdown 表格（`|`）、禁 LaTeX（`$`、`\frac`）、禁 HTML
- ⛔ 不抄题库题干；讲解里引题一律用卷面原文的关键短句（≤20 字），换句复述即可
- 单位按教材写法：`3 m/s`、`2 kg`、`220 V`（数字与单位间留空格）；物理符号 `× ÷ ＋ － ＝`

## 分段建议配额（按 5500 字规划）
- 一、这份卷在考什么 400–600
- 二、考点地图：按知识点归并，每题一行「第 a–b 题 → 知识点 → 分值」，末行给最重三个考点
- 三、逐题精讲 ≈3000（占全文 ≥60%）：选择题点明干扰项错因；实验/计算题按 `scoreRule` 的分步给分讲
- 四、整卷复盘 500–700：三类高频错因 + 时间分配 + 作答顺序
- 五、五步学习法 300–700
- 六、自查清单 6–8 条

```
python3 scripts/check_pgy_lecture.py --file <你的产物绝对路径>
```

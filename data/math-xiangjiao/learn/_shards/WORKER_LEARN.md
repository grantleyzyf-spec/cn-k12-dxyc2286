# 湘教版数学「学层精讲」工位合同 · W3

## 你的活
读派单 `data/math-xiangjiao/learn/_shards/<LID>.json`（含 `book`、`txt_tag`、`lessons[]`，每篇给 `topicId / name / chapter / page / misconceptions / txt`），
为**每个课时点**写一篇七段精讲，落到派单 `out` 指定的 `data/math-xiangjiao/learn/_parts/<LID>.json`，并跑自检到 PASS：

```bash
cd ~/Desktop/cn-k12-dxyc2286
python3 scripts/check_math_xiangjiao_learn.py data/math-xiangjiao/learn/_parts/<LID>.json
```

⛔ 只写自己那一个 `_parts/<LID>.json`；不改题库、骨架、别人的分片、试卷。

## 教材原文从哪来
- 逐页 OCR：`/tmp/mxj/<txt_tag>/ocr/pNNN.txt`（三位补零）。派单里 `lessons[].txt` 已给出多数课的起始页。
- **`txt` 为空或页面内容对不上**时：在本册 OCR 目录里按课时名关键词检索（例如「认识4、5」用「认识」+「4」「5」分别 grep），
  或从本章起始页起顺读 10–20 页定位；找到该课正文后再引用。
- 原文**逐字照抄**，不改写、不合并两句；OCR 把数学符号读变形的（如「犃」「狓」「犿」），按教材原意写回正确符号，但句子结构不动。

## 输出结构
```json
{"book": "湘教版一年级上册", "lessons": [{"topicId": "msj_p1001", "title": "我和我的幼儿园", "markdown": "…", "words": 1800}]}
```
`words` = markdown 的汉字数（`[\u4e00-\u9fa5]`，允许 ±50）。

## 七段（标题逐字，`## ` 开头，顺序不可换）
1. `## 一、先说生活里的一件事`（2–3 个具体情形，末句点出本课要解决的问题）
2. `## 二、课本原文说了什么`（**≥2 处** `> ` 引用块，每条 ≥8 汉字，逐字取自本册 OCR；每处紧跟「这句话的意思是：……」）
3. `## 三、费曼翻译：用大白话说清楚`（打比方 + 一句话版本 + 讲清机制，不喊口号）
4. `## 四、例题精讲`（**≥2 道**，写「例 1」「例 2」；每道必须有 `❌ 常见错法` 与 `✅ 正确做法`；全文 ❌/✅ 各 ≥2）
5. `## 五、易错点拨`（取该点 `misconceptions`，说清为什么错、怎么自查）
6. `## 六、五步学习法：这一课怎么吃透`（**恰好 5 条**，`1. ` 起头，每条 ≥25 汉字，本节合计 350–700 汉字；五条依次落到 **锻炼 / 第一个知识点 / 积微 / 对标 / 杠铃**）
7. `## 七、方法锚与自查`（一句话方法锚 + `- [ ]` 自查清单 ≥3 条）

## 硬性规则
- 全篇 1200–2600 汉字；本桶含初中 5 册与高中 3 册，用词按对应学段，不出超纲内容。
- 题干/正文纯文本，禁 Markdown 符号（`* _ # [ ] |`）与 LaTeX；公式写 `2^3`、`√2`、`x²` 这类纯文本。
- 不写元话语（「扫描件」「OCR」「抽取」等），把教材当读者手里的干净课本。

## 交付
文件 UTF-8 无 BOM；回复一行：`LID / 篇数 / 每篇汉字数 / checker 末行`。

# 粤教粤人版初中地理 · 学层精讲分片合同（GYJ_L01–L38）

## 0. 任务

一片 4 篇（同一册的连续 4 个课时）。只写自己那一片的文件，不碰别的分片、不改仓库其他文件、不跑 git。

- 分片规格（只读）：`data/geography-yuejiao/_learn_shards/GYJ_Lnn.json`
- 教材全文（只读）：`data/geography-yuejiao/_text/<册>.txt`（规格里的 `text_file`）
- 落盘（只写这一个文件）：规格里的 `out` 字段，形如 `data/geography-yuejiao/learn/_parts/七年级上册/GYJ_L01.json`

## 1. 输出形状

```json
{"book": "七年级上册",
 "lessons": [
   {"topicId": "gyj_p002", "title": "地球的形状与大小", "words": 1680,
    "markdown": "## 一、开场\n\n……"}
 ]}
```

4 篇齐全，`topicId`/`title` 逐字照抄规格。

## 2. 七段固定标题（**逐字**，不得改写成同义句）

```
## 一、开场
## 二、课本原文
## 三、费曼翻译
## 四、例题精讲
## 五、易错点拨
## 六、五步学习法
## 七、自查清单
```

除这七个外**不许出现任何其它 `#` 标题**。

## 3. 每段写什么

1. **开场**（200–300 字）：从一个具体生活场景或一个真实疑问切入这一课，不写「本节我们来学习……」这类套话。
2. **课本原文**：**至少 2 处**以 `> ` 开头的引文，逐字来自本册教材全文；每处引文后面紧跟一句「这句话的意思是……」把它翻译成人话。
3. **费曼翻译**（300–400 字）：把这一课的核心概念讲给一个没学过地理的人听，用类比、打比方，不用术语堆砌。
4. **例题精讲**：**2 道**题，各含题干、`❌` 的错误思路与错因、`✅` 的正确思路与答案。
5. **易错点拨**：2–3 个学生真会踩的坑（概念混淆、读图看错、单位换算错），每个说清「错在哪、怎么避免」。
6. **五步学习法**：**必须**按这五条固定顺序、固定说法写，每条 70–90 汉字（整节 350–900 汉字）：
   - 每天锻炼一个小时
   - 扎实掌握第一个知识点
   - 能积微者速成
   - 运用对标思维突破学习困境
   - 运用杠铃法则缓解学习疲劳
   每条都要落到**这一课的具体做法**（读哪张图、背哪几个数、练哪一步），不要写成通用鸡汤。
7. **自查清单**：≥3 条 `- [ ] ……`，每条是这一课可自测的具体动作。

全篇 **1200–2800 汉字**（写 1500–1800 最稳），`words` 字段填你实测的汉字数（与正文实测差 ≤10）。

## 4. 引文必须逐字回表（最容易翻车的一条）

`> ` 引文会被 checker 拿去与本册教材全文做**去空白子串**比对，一个字不同就判「引文失配」。做法：

```bash
cd ~/Desktop/cn-k12-dxyc2286
grep -n "经线" data/geography-yuejiao/_text/七年级上册.txt | head -20
```

从 grep 结果里**整句复制**（原文可能有 OCR 断字、异体字，照抄原样，不要「顺手改通顺」）。

## 5. 禁则

- 禁词：首先、其次、综上所述、总而言之、由此可见、赋能、抓手、闭环、值得注意的是。
- 禁 Markdown 表格与代码块；正文只用自然段。
- 禁写「扫描件 / OCR / 抽取 / 文字层」这类元话语。
- 禁把教材没有的数据、年份、地名编进去。

# 粤教粤人版初中地理 · 试卷讲解合同（每卷一份）

## 0. 任务

给**一份卷**写一份讲解，5000 字上下。只写自己这一卷，不改仓库其他文件、不跑 git。

- 试卷（只读）：`data/geography-yuejiao/exams/<book>/<paper>.json`
- 诊断题库（只读，可引用同类题思路）：`data/geography-yuejiao/questions.json`
- 落盘：`data/geography-yuejiao/exam_lectures/<book>/<paper>.json`

## 1. 输出形状

```json
{"examId": "gyj_exam_g7a_u01", "book": "七年级上册", "paper": "第一单元 地理工具与地理实践 测试卷",
 "kind": "unit", "words": 5120, "markdown": "## 一、这份卷在考什么\n\n……"}
```

`examId`/`book`/`paper`/`kind` 逐字照抄试卷 JSON；`words` 填实测汉字数（与正文差 ≤6）。

## 2. 六段固定标题（逐字，不许改写）

```
## 一、这份卷在考什么
## 二、考点地图
## 三、逐题精讲
## 四、整卷复盘
## 五、五步学习法
## 六、自查清单
```

## 3. 每段写什么

1. **这份卷在考什么**（400–600 字）：这份卷覆盖哪些单元/知识点、分值怎么分布、难度结构（基础/标准/难题各几道、题号列出）、这份卷想测的核心能力。
2. **考点地图**：按知识点归并，写清「哪个点 → 哪几题 → 共多少分」，**末行给最重的三个考点**（写出分值）。
3. **逐题精讲**（主体，约 3000 字）：**24 道题一道不落**，每题按下面四要素写：
   - 先写「第 N 题（X 分）」——分值必须与卷面一致；
   - **思路**：这题在问什么、从哪入手；
   - **关键一步**：真正决定对错的那一步（读图看哪、算哪一步、排除哪一项）；
   - **易错**：学生最可能错在哪、为什么错；
   - 选择题要说明错项为什么错；综合题按 `scoreRule` 的分步给分逐条讲。
4. **整卷复盘**（500–700 字）：这份卷暴露的三个共性问题、对应的补救动作、下次做题的顺序策略。
5. **五步学习法**（250–750 字）：五条固定说法逐字用，每条落到这份卷的具体题上：
   - 每天锻炼一个小时
   - 扎实掌握第一个知识点
   - 能积微者速成
   - 运用对标思维突破学习困境
   - 运用杠铃法则缓解学习疲劳
6. **自查清单**：≥6 条 `- [ ] ……`，每条可自测、可勾选。

全文 **4000–7800 汉字**（写 5000–6000 最稳）。

## 4. 硬性判据（checker 逐条查）

- 「思路」出现 ≥ 题数×0.9（24 题→≥21 次）；「关键一步」≥ 题数×0.6（≥14 次）；「易错」≥ 题数×0.9（≥21 次）。
- 每个题号都要出现，写作「第 N 题」（阿拉伯数字）。
- 若写「第 N 题（X 分）」，X 必须等于卷面该题分值。
- 禁 LaTeX（`$`、`\frac`）、禁 HTML 标签、禁 Markdown 表格；数字与单位之间空一格（写 `3 km`，不要 `3km`）。
- 禁写「分五段/按五段/五个部分」。

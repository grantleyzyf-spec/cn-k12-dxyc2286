# 中图版（钟作慈）地理 学层精讲工位合同（L01–L18）

## 0. 产物

一个文件：`data/geography-zhongtu-cz/learn/_parts/LNN.json`

```json
{"shard":"L01","book":"七年级上册","unitPoint":"gztu_u001","unitLabel":"我们共同学地理",
 "lessons":[
   {"topicId":"gztu_j001","book":"七年级上册","title":"地理第一课·我们共同学地理","grade":7,
    "chapter":"七年级上册 绪论 我们共同学地理 · 第1课时 地理第一课·我们共同学地理",
    "unitLabel":"我们共同学地理","words":2100,
    "markdown":"<七段正文>"}]}
```

`lessons` 必须与派单 `_learn_shards/LNN.json` 的 lessons **一一对应**（topicId 集合相等，顺序照派单），一节一篇。

## 1. 正文七段（标题逐字，顺序不可换）

```
一、开场
二、课本原文
三、费曼翻译
四、例题精讲
五、易错点拨
六、五步学习法
七、自查清单
```

硬判据（`check_geo_ztu_learn.py`）：

- 全篇 **1200–2600 汉字**（`words` 字段写实际汉字数）。
- **二、课本原文**：至少 **2 处** 以 `> ` 开头的引文，内容必须**逐字**出现在该册 textpack（`整册全文.txt` 或 `ocr/pNNN.txt`）里；不许改写、不许拼接。引文后可用一句白话接住。
- **三、费曼翻译**：把课本原话翻成初一学生能听懂的话，讲「为什么」，不堆术语。
- **四、例题精讲**：至少一题，必须同时出现 `❌`（错解）与 `✅`（正解），并讲清错在哪一步。
- **五、易错点拨**：2–3 个真实易错点（混淆概念/读图看错/条件漏看）。
- **六、五步学习法**：**350–700 汉字**，五条固定序逐字：
  `每天锻炼一个` / `扎实掌握第一个知识点` / `能积微者速成` / `对标思维` / `杠铃法则`，每条结合本课时内容具体化，不许只喊口号。
- **七、自查清单**：≥3 条 `- [ ]` 勾选项，可测。
- 禁 Markdown 富文本：`**`、`##`、`|`、`$`、`\frac` 一律不许（`> ` 与 `- [ ]` 是唯一允许的标记）。
- 禁元话语：`扫描件`、`OCR`、`抽取`、`切片`、`文字层`、`残片`。
- 文风：面向学生的讲稿，短句为主，不写「本节课我们将……」这类空话；事实、数据、地名以教材原文为准。

# 中图版（钟作慈）初中地理 —— 试卷讲解工位合同（K01–K04 同用）

你负责一册的若干卷（`_lecture_shards/KNN.json` 的 `papers[]`）。每卷写一份讲解。

## 0. 产物

`papers[].out` 指定路径（`data/geography-zhongtu-cz/exam_lectures/<册>/<卷名>.json`）：

```json
{"book":"七年级上册","paper":"期中测试卷A","examId":"…","kind":"mid","words":5200,"markdown":"…"}
```

## 1. 六段结构（标题逐字）

```
## 这份卷在考什么
## 考点地图
## 逐题精讲
## 整卷复盘
## 五步学习法
## 自查清单
```

- **这份卷在考什么**：本卷范围、分值结构、能力侧重，300–500 字。
- **考点地图**：按知识点列「考了什么 / 第几题 / 多少分」；**末行给出最重的三个考点**。
- **逐题精讲**：**每一题都要讲到**，题号写法统一为「第 N 题」（N 为阿拉伯数字）。
  每题写：`思路`（怎么想）、`关键一步`（决定性的那一步）、`易错`（学生常错在哪）。
  全篇「思路」出现次数 ≥ 22、「关键一步」≥ 14、「易错」≥ 22（24 题口径）。
  综合题按 `scoreRule` 分步给分，各步分值之和必须等于该题分（11 分）。
  若写「第 N 题（M 分）」，M 必须与卷面 score 一致。
- **整卷复盘**：失分结构、三类高频错误、下一轮复习建议，400–600 字。
- **五步学习法**：五条固定序**逐字**：每天锻炼一个小时 / 扎实掌握第一个知识点 / 能积微者速成 /
  运用对标思维突破学习困境 / 运用杠铃法则缓解学习疲劳；该节 250–750 汉字，每条之间空行。
- **自查清单**：`- [ ]` **≥6 条**。

## 2. 字数与禁则

- 初中：**4000–7800 汉字**（目标 4800–6200）。
- 禁：`分五段`、`按五段`、`五个部分`（结构已是六段）。
- 禁 LaTeX（`$`、`\frac`、`\sqrt`）、禁 HTML 标签、禁 Markdown 表格竖线。
- 数值与单位之间空一格（写 `3 千米`，不写 `3千米`；百分号 `50%` 直接连写）。
- 讲解必须与卷面一致：题号、题分、答案、选项都以 `examPath` 指向的卷为准，⛔ 不许另写一套。

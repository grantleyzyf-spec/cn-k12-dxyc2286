# 合同 · 沪科教版高中物理「学层精讲」工位（七段固定，一片两篇）

## 0. 你只写一个文件
`data/physics-hkjy/_learn_parts/<LID>_out.json`（你的 LID 见分子），形状：
```json
{"lessons":[{"book":"必修第一册","topicId":"phk_j001","title":"运动与质点模型","words":1834,"markdown":"## 一、开场\n\n…"}]}
```
`words` = markdown 的**汉字数**（`len(re.findall(r"[\u4e00-\u9fa5]", md))`），必须与实测一致（±10 内）。
`title` 用片子里给的 `name`，逐字不改。

## 1. 七段固定（标题逐字，顺序不许变）
`## 一、开场` / `## 二、课本原文` / `## 三、费曼翻译` / `## 四、例题精讲` / `## 五、易错点拨` / `## 六、五步学习法` / `## 七、自查清单`

- **每篇 1200–2800 汉字**（目标 1600–2200）。
- **二、课本原文**：≥2 处 `> 引文`，**必须是本册教材原文的连续片段**（逐字，不得改写/拼接），
  取自 `data/physics-hkjy/_text/<book>.txt`（带 `[[pN]]` 页标）；每处引文后紧跟一句「这句话的意思是……」。
- **四、例题精讲**：2 道题，各配 `❌ 常见错解` 与 `✅ 正确思路`（两个符号都要出现），数值要算对。
- **五、易错点拨**：2–3 个易错点，写清「错在哪、为什么错、怎么改」。
- **六、五步学习法**：逐字出现这五条（顺序固定）：
  `每天锻炼一个小时`、`扎实掌握第一个知识点`、`能积微者速成`、`运用对标思维突破学习困境`、`运用杠铃法则缓解学习疲劳`；
  每条写 **72–88 汉字**的具体做法（落到本节物理内容），整节 350–900 汉字。导语里**不要**提前出现「五步学习法」四字。
- **七、自查清单**：`- [ ]` 勾选项 ≥3 条。

## 2. 硬规则
- ⛔ 禁词：首先、其次、综上所述、总而言之、由此可见、赋能、抓手、闭环、值得注意的是。
- ⛔ 除七段标题外不得出现其他 `#`/`##`/`###` 小节标题；禁 `**加粗**`、禁表格竖线 `|`。
- ⛔ 禁 LaTeX（`$`、`\frac`、`^{}`）；公式用普通写法：`v=s/t`、`m/s²`、`×10⁻⁹`。
- 术语按沪科教版教材；可引用教材图号与数据（如「图1-1-2」「g 取 10 m/s²」）。
- ⛔ 只写本课时内容，不写邻节；不写「本课是第X单元第Y节」这类编排元话。

## 3. 自检（写完必跑）
```bash
/usr/bin/python3 scripts/check_phys_hkjy_learn.py data/physics-hkjy/_learn_parts/<LID>_out.json
```
回报一行：`<LID> ｜ 篇 n ｜ 字数 a/b ｜ 七段齐 ｜ 引文 n ｜ 自检 OK/FAIL`。

# 合同 · 沪科教版高中物理「试卷讲解」工位（六段固定）

## 0. 你只写一个文件
卡片 `_lecture_parts/<XID>.json` 里 `out` 指定的 `<XID>_out.json`，形状：
```json
{"markdown":"## 一、这份卷在考什么\n\n…","words":6210}
```
`words` = markdown 的**汉字数**（`len(re.findall(r"[\u4e00-\u9fa5]", md))`），须与实测一致。
⛔ 先读卡片指向的**卷面 JSON**，逐题按真实 `no / score / answer / stem` 写；⛔ 不许改卷面、不许编题。

## 1. 六段固定（标题逐字，顺序不许变）
`## 一、这份卷在考什么` / `## 二、考点地图` / `## 三、逐题精讲` / `## 四、整卷复盘` / `## 五、五步学习法` / `## 六、自查清单`

- **全篇 4500–8800 汉字**（高中带）。逐题精讲占 ≥60%。
- **三、逐题精讲**：每题一个小标题 `**第 N 题（X 分）**`，题号与分值**逐字等于卷面**；
  每题必须四要素齐（`答案：` / `思路：` / `关键一步：` / `易错：`），且：
  **「思路」出现次数 ≥ 22、`关键一步` ≥ 15、`易错` ≥ 22**（24 题以上按题数×0.9/0.6/0.9）。
  选择题点明每个干扰项错因；计算题写出完整步骤与单位。
- **二、考点地图**：按大题列所考课时点（用 topics.json 的真实课时名），末行写分最重的三个考点。
- **五、五步学习法**：逐字出现 `每天锻炼一个小时`、`扎实掌握第一个知识点`、`能积微者速成`、
  `运用对标思维突破学习困境`、`运用杠铃法则缓解学习疲劳`，每条绑定本卷具体题号。
- **六、自查清单**：`- [ ]` ≥6 条。

## 2. 硬规则
- ⛔ 公式不用 LaTeX（禁 `$`、`\frac`、`\sqrt`）；写 `v=s/t`、`E=kQ/r²`。
- ⛔ **数值与单位之间空一格**：`20 m/s`、`9.8 N`、`3 kg`（写 `20m/s` 会被判错）。
- ⛔ 禁 HTML、表格竖线、`**加粗**` 以外的 Markdown（小标题的 `**第 N 题（X 分）**` 允许）。
- ⛔ 禁词：首先、其次、综上所述、总而言之、由此可见、赋能、抓手、闭环、值得注意的是。
- 引文与数据必须来自本卷题干；核算过的数值要与卷面答案一致。

## 3. 自检（写完必跑）
```bash
python3 scripts/check_exam_lecture.py <你的 _out.json 不行：先合并> 
```
工位内先自查字数与四要素：
```bash
/usr/bin/python3 - <<'PY'
import json,re
d=json.load(open("<out>",encoding="utf-8")); md=d["markdown"]
h=lambda s: len(re.findall(r"[\u4e00-\u9fa5]",s))
print("汉字",h(md),"words",d["words"],"思路",md.count("思路"),"关键一步",md.count("关键一步"),"易错",md.count("易错"),"- [ ]",md.count("- [ ]"))
for s in ["一、这份卷在考什么","二、考点地图","三、逐题精讲","四、整卷复盘","五、五步学习法","六、自查清单"]:
    if s not in md: print("缺段",s)
PY
```
回报一行：`<XID> ｜ 卷名 ｜ 汉字 n ｜ 题数 k ｜ 思路/关键一步/易错 a/b/c ｜ 六段齐`。

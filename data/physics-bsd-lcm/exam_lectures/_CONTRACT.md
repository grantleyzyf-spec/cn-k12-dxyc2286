# physics-bsd-lcm 试卷讲解合同（北师大版·李春密·初中物理）

## 交付物
每份卷配一份讲解：

```
…/data/physics-bsd-lcm/exam_lectures/<册>/<卷名>.json
```

```json
{"book":"八年级全一册","paper":"第1章 热现象 测试卷","words":5200,
 "markdown":"## 这份卷在考什么…"}
```

## 六段（标题逐字，⛔ 不许改）
```
## 这份卷在考什么
## 考点地图
## 逐题精讲
## 整卷复盘
## 五步学习法
## 自查清单
```

## 硬指标（checker 逐条查）
- 全篇汉字 **4000–7800**（初中带），`words` 与实测差 ≤6。
- **每一个题号都要讲到**：正文出现「第 1 题」…「第 24 题」，一个都不能漏。
- 逐题精讲里必须写到的词：`思路`（≥0.9×题数）、`关键一步`（≥0.6×题数）、`易错`（≥0.9×题数）。
- 讲解里若写「第 N 题（X 分）」，X 必须与卷面该题分值一致。
- 五步学习法五条**逐字**：`每天锻炼一个小时` / `扎实掌握第一个知识点` / `能积微者速成` / `运用对标思维突破学习困境` / `运用杠铃法则缓解学习疲劳`；该节 250–750 汉字；相邻两条之间留空行。
- 禁：HTML 标签、Markdown 表格、LaTeX。
- 数字与单位之间要**空一格**（写 `3 m/s`、`2 kg`、`5 cm`；⛔ 不写 `3m/s`）。

## 内容要求
- 精讲要按卷面原题走：给出思路 → 关键一步 → 完整解答 → 易错点（为什么错、下次怎么避）。
- 选择题要说明其它三项错在哪；计算题按卷面 `scoreRule` 的分步给分讲。
- 考点地图：按知识点归并，末行给「最重的三个考点」。
- 整卷复盘：得分分布、共性失误、下一轮复习建议（落到本册具体章节）。

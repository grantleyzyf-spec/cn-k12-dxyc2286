批次根：`/Users/a627692/Desktop/cn-k12-dxyc2286/data/physics-bsd-lcm`

## 交付物
按卡片分片号写一个文件：

```
…/data/physics-bsd-lcm/_learn_shards/PLCM_Lxx_out.json
```

```json
{"book": "八年级全一册",
 "lessons": [{"topicId": "plcm_j001", "title": "温度及其测量", "words": 2130, "markdown": "## 一、先从一个生活场景说起…"}]}
```

- 篇目、`topicId`、`title` 全部照分片 spec 的 `lessons[]`（**一篇不多、一篇不少**）。
- `words` = 该篇正文汉字数（`[\u4e00-\u9fa5]` 计数），与实测差 ≤50。

## 七个小节（标题逐字，⛔ 不许改写）
```
## 一、开场：先从一个生活场景说起
## 二、课本原文
## 三、费曼翻译：把它说成人话
## 四、例题精讲
## 五、易错点拨
## 六、五步学习法
## 七、方法锚与自查
```
checker 按 `开场 / 课本原文 / 费曼翻译 / 例题 / 易错 / 五步学习法 / 自查` 七个词切节 ⇒ 这七个词**只准出现在上面这七个小标题里**，正文里不要提前出现（会被切错段：比如正文写「最容易出错的地方」会把「易错」段切在正文中间）。

## 硬指标
- 全篇汉字 **1200–2600**；其中第六节（五步）**350–700**，五条每条 **72–88 汉字**。
- 第二节「课本原文」：`> ` 引用 **≥2 处**，每处 ≥8 汉字，**逐字复制**自本册全文（`…/_text/<册>/整册全文.txt`）。教材是扫描 OCR，含字形噪声：照抄原文，⛔ 不许把 OCR 错字改成你认为正确的字，否则回表失配。
- 第四节：**≥2 道**例题，每道都要有 `❌ 常见错法：…` 与 `✅ 正确做法：…`（每个各 ≥2 处）。
- 第五节：≥1 处物理易错点（单位/方向/条件/图像读法）。
- 第七节：`- [ ]` 自查 ≥3 条。
- 第六节五步标题逐字：`每天锻炼一个小时` / `扎实掌握第一个知识点` / `能积微者速成` / `运用对标思维突破学习困境` / `运用杠铃法则缓解学习疲劳`。
- 禁：LaTeX（`$…$`）、HTML 标签、Markdown 表格、`**` 加粗可以但要少。

## 怎么找原文
1. `grep -n "<课时名>" …/_text/<册>/整册全文.txt` 定位，`sed -n 'a,bp'` 读该节正文（一般 2–6 页）。
2. 只挑**完整、无乱码**的句子做引文（避开表格、图注、页码行）。

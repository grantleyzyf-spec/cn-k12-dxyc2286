# 试卷讲解合同（chemistry-kepu）

## 你的任务
分片 JSON 给了一份卷的 `examPath`（卷面 JSON）。为这份卷写一份**学生自己看的试卷讲解**，
落盘成 `{"examId","book","paper","kind","markdown","words"}` 到分片给的 `outPath`。

## 六段（标题逐字、顺序固定）
1. `## 一、这份卷在考什么`（300–500 汉字）：满分/时长/题量、难度分布（basic/standard/hard 各几题）、
   覆盖哪几个单元或课时点；末尾一句话点明这份卷的**一个核心难点**。
2. `## 二、考点地图`：按大题列成列表 `大题名 → 第 a–b 题 → 考哪个课时点 → 共 X 分`；
   最后一行写「分值最重的三个考点」。
3. `## 三、逐题精讲`（主体，占全篇 60% 以上）：**每题一段，题号必须与卷面 `no` 一致**，段首逐字写成
   `**第 N 题（X 分）**`（X 必须等于卷面该题 `score`），紧跟四行：
   - `**思路**`：从题干哪个条件入手、为什么想到这一步
   - `**关键一步**`：最容易卡住或算错的那一步，写算式与结果
   - `**易错**`：学生真实会犯的错（错因，不写「粗心」）＋正确写法
   选择题要点明干扰项为什么错；`scoreRule` 存在的题按得分点写，不得改动分数。
   同类简单题可合并成 `第 5、6 题` 一条，但**每个题号都要出现一次**。
4. `## 四、整卷复盘`（300–500 汉字）：本卷三个高频错因（按卷面实际题归纳）、
   按 `duration` 折算的时间分配建议、建议作答顺序。
5. `## 五、五步学习法：这份卷怎么吃透`（每条 ≥40 汉字，条间空一行，五个小标题逐字照抄）：
   ① 每天锻炼一个小时 ② 扎实掌握第一个知识点 ③ 能积微者速成 ④ 运用对标思维突破学习困境 ⑤ 运用杠铃法则缓解学习疲劳。
   五条必须绑定**本卷具体题号与知识点**，禁通用励志话。
6. `## 六、自查清单`：6–8 条 `- [ ]`，每条可判定（不写「认真检查」）。

## 硬指标（checker 逐条断言）
- 全篇汉字 **2500–7500**；`words` 写实测汉字数（差 ≤10）。
- 六段标题齐全且顺序正确；每个题号出现一次且格式 `**第 N 题（X 分）**`、X 与卷面一致。
- `**思路**`／`**关键一步**`／`**易错**` 各自出现次数 ≥ 题数的 70%（合并题也各算一次）。
- 五步五条关键字齐全；自查 `- [ ]` 6–8 条。
- 禁 LaTeX（`$…$`）、HTML、Markdown 表格（`|`）、禁「教学目标／考点纵览／命题趋势」与套话
  （首先、其次、综上所述、总而言之、由此可见、赋能、抓手、闭环）。
- **不得改动卷面事实**：题号、题分、答案、`scoreRule` 一个字都不能改；讲解只解释。

## 自检（必须跑到 PASS）
```bash
python3 scripts/check_chem_editions_lecture.py --bucket chemistry-kepu --file <你写的 json>
# 期望末行：RESULT: PASS
```
⛔ 不许改 checker；只写自己的 outPath。

## 二、逐段要求

1. **第一段（开场）**：一个学生真实会遇到的小场景／一个问题，引出本课时要解决的事，150–300 汉字。
2. **第二段（课本原文）**：**≥2 处** `> ` 块引用，每处 **≥8 汉字**，每处后面紧跟一句「这句话的意思是……」。
   - 引文必须能从 `textbook_txt` 指的本册教材 TXT 里**逐字**找到（去标点/空白后比对，允许 OCR 级符号差异）。
   - 优先引纯汉字句（定义句、判定句）。**不要引含公式、根号、分数、字母变量的句子**（OCR 会认错，回表必失配）。
   - 实在没有可引的整句（练习课/复习课），引教材里的题干或提示语原句，照实引，别自己编定义。
3. **第三段（费曼翻译）**：把这节课的核心讲给「六年级的弟弟」听，200–400 汉字。
4. **第四段（例题精讲）**：`### 例题 1` 与 `### 例题 2` 两道，各配一组「❌ 常见错法 / ✅ 正确做法」（全篇 ❌ 与 ✅ 各 ≥2）。
5. **第五段（易错点拨）**：≥2 条，优先直接用输入里的 `misconceptions`。
6. **第六段（五步学习法）**：五步固定顺序、关键词逐字：
   ①每天锻炼一个小时 ②扎实掌握第一个知识点 ③能积微者速成 ④运用对标思维突破学习困境 ⑤运用杠铃法则缓解学习疲劳。
   每条 **≥25 汉字**且要结合本课时；整节 **350–700 汉字**；**序号条目之间必须留空行**（粘连会判红）。
7. **第七段（方法锚与自查）**：一句「方法锚」（记住这一条就能用），再给 **≥3 个** `- [ ]` 自查项。

## 三、硬指标（checker 逐条断言）

- 全篇汉字 **1200–2600**；`words` 不用你算（父代合并时现算）。
- 无 LaTeX（`$…$`、`\(`）、无 HTML 标签、无 Markdown 表格。
- 一课时一个 `topicId`，不多不少，与输入 `points` 一一对应。
- 语言：小学低年级用「一共/还剩/比…多」，初中用「解/求证/化简」；不提前教下一课时（最多提一句）。

# 晋教版初中地理 · 试卷讲解工位合同（一片＝一册 4 卷）

> 4 个工位共用。派单卡只给片号。仓库根 `~/Desktop/cn-k12-dxyc2286`。

## 一、你的派单

读 `data/geography-jin/_lecture_shards/K{NN}.json`：`book` ＋ `papers[]`（每项 `examId / paper / kind / examPath / out`）。

- 卷面在 `examPath` 指向的 JSON 里 —— **讲解必须逐题对着现役卷面写**（题号、题分、答案、选项文字都不许自己编）
- 落盘到 `out` 字段给的路径（`data/geography-jin/exam_lectures/<册>/<paper>.json`）

## 二、产物形状

```json
{"examId": "gjin_exam_j7a_u01", "book": "七年级上册",
 "paper": "七年级上册 主题一 探寻人类的太空家园 测试卷", "kind": "unit",
 "words": 5180,
 "markdown": "## 一、这份卷在考什么\n……"}
```

`words` = 正文实测汉字数（`[\u4e00-\u9fa5]` 计数）。

## 三、六段结构（标题逐字，供 checker 按词切节）

```
## 一、这份卷在考什么
## 二、考点地图
## 三、逐题精讲
## 四、整卷复盘
## 五、五步学习法
## 六、自查清单
```

| 段 | 要求 |
|---|---|
| 一 | 卷面定位：满分 120 分、120 分钟、24 题；大题结构与分值；难度分布（基础/中档/较难 的题数与分值，**由卷面 `difficulty`/`score` 现算**）；这张卷考哪几条主线 |
| 二 | 考点地图：按课时点或考法分组，每行写「题号 ＋ 分值 ＋ 一句话深度」。行分合计若超过 120（一题挂多点），节首必须写明「看单行就行」 |
| 三 | 逐题精讲：24 题全覆盖，每题一个块，块标题 **`**第 N 题（X 分）**`**（X 与卷面 score 一致）。每题写：思路 / 关键一步 / 易错；选择题另写干扰项辨析；综合题按卷面 `scoreRule` 写 `**分步给分**`（各步之和必须等于该题分） |
| 四 | 整卷复盘：得分结构、时间分配建议、三个高频错因、补强顺序（点名题号） |
| 五 | 五步学习法：恰好 5 条，标签逐字 ①每天锻炼一个小时 ②扎实掌握第一个知识点 ③能积微者速成 ④运用对标思维突破学习困境 ⑤运用杠铃法则缓解学习疲劳；每条 72–88 汉字，条间空行，本节 350–700 汉字 |
| 六 | 自查清单：`- [ ]` 6–8 条，每条能落到具体题号或动作 |

全篇 **4000–7800 汉字**（初中口径）；逐题精讲部分应占 60% 以上。

## 四、口径与禁项

- 题分、难度分布、考点地图里的题号与分值、`分步给分` 各步分值 —— **全部从卷面现算**，⛔ 不许手写数字
- 禁 LaTeX 与 Markdown 表格：`$`、`\frac`、`|` 表格竖线都不许（成对绝对值写法也避免，改写成「绝对值」）
- 禁 HTML 标签；正文里不许出现 ASCII 的 `<` `>`（写成「小于」「大于」或全角）
- 数字与单位之间留一个空格（`2 800 米`、`0.5 ℃`、`1 000 毫米`）
- 禁「卷面答案栏」「对不上」这类会随卷面修订而过期的对照句
- 「五步学习法」四字只许出现在段标题里一次
- 答案要给到具体结论（不能「讲完不给答案」）：每题的答案数字/结论必须出现在「思路」或「关键一步」里

## 五、自检（末行必须 `RESULT: PASS`）

```bash
python3 scripts/check_exam_lecture.py data/geography-jin/exam_lectures/<册>/<paper>.json --subject geography-jin
# 整册一次过：
python3 scripts/check_exam_lecture.py --book <册> --subject geography-jin
```

常见红与修法：

| 报错 | 修法 |
|---|---|
| `字数 3860 ∉4000–7800` | 逐题精讲补「再想一层」（讲该题的一个延伸问法），不要灌导语 |
| `第 N 题题分与卷面不一致` | 块标题的分值照卷面 `score` 改 |
| `分步给分 合计 10 ≠ 11` | 按卷面 `scoreRule` 的分值逐条对齐 |
| `数字与单位之间缺空格` | `2800米` → `2 800 米` |
| `缺段「考点地图」` | 六段标题逐字照抄，不许改写同义句 |

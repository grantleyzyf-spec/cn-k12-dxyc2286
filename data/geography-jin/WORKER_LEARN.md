# 晋教版初中地理 · 学层精讲工位合同（一片＝一个主题的 8 篇）

> 16 个工位共用。派单卡只给片号。仓库根 `~/Desktop/cn-k12-dxyc2286`。

## 一、你的派单

读 `data/geography-jin/_learn_shards/L{NN}.json`：

| 字段 | 用处 |
|---|---|
| `book` / `chapter` / `unitLabel` | 册次与主题，写进每篇 front matter 与正文 |
| `txt` | **本册教材全文的绝对路径**，引文只能从这里取 |
| `out` | 你的落盘路径（`data/geography-jin/learn/_parts/LNN_<册>.json`） |
| `lessons[]` | 8 个课时点：`topicId` / `title` / `chapter` / `grade` / `standards` |

## 二、产物形状

```json
{"shard": "L01", "book": "七年级上册", "lessons": [
  {"topicId": "gjin_j001", "book": "七年级上册", "title": "地球在太阳系中的位置",
   "words": 1834, "markdown": "## 一、开场\n……"},
  …8 篇…
]}
```

- `title` 逐字等于派单里的 `title`
- `words` 必须等于正文实测汉字数（`[\u4e00-\u9fa5]` 计数，写完自己算一遍再填）
- 只写这 8 篇，⛔ 不写别的主题

## 三、七段结构（标题**逐字**照抄，供 checker 按词切节）

```
## 一、开场
## 二、课本原文
## 三、费曼翻译
## 四、例题精讲
## 五、易错点拨
## 六、五步学习法
## 七、自查清单
```

| 段 | 要求 |
|---|---|
| 一、开场 | 从一个具体的地理情境/现象切入（不是「本节课我们将学习」这类套话） |
| 二、课本原文 | **≥2 处** `> ` 引文，逐字取自本册 textpack，每处后面紧跟一句「这句话的意思是……」 |
| 三、费曼翻译 | 把本课核心概念讲给外行听：类比 ＋ 反例，讲清「为什么」 |
| 四、例题精讲 | **2 道**例题，各配 ❌（典型错解）与 ✅（正确解法），要有读图/分析过程 |
| 五、易错点拨 | 3 个具体易错点，每个说清「错在哪、怎么改」 |
| 六、五步学习法 | 恰好 5 条，标签逐字：①每天锻炼一个小时 ②扎实掌握第一个知识点 ③能积微者速成 ④运用对标思维突破学习困境 ⑤运用杠铃法则缓解学习疲劳；每条 **72–88 汉字**，条间空行，本段合计 **350–700 汉字** |
| 七、自查清单 | `- [ ]` ≥3 条（建议 6 条），每条对应本课一个可自测的动作 |

全篇 **1200–2600 汉字**。

## 四、引文怎么取（唯一方法）

```bash
F="<派单里的 txt>"
grep -n "宜居带" "$F"        # 找行号
sed -n '210,260p' "$F"       # 读那一段，挑一句完整的原句
```

- 引文必须与教材**逐字**一致（去掉空白与标点后是全文的子串）
- 引文长度 12–40 字，一句完整的话，不要跨栏拼接
- ⛔ 不要通读全册，⛔ 不要用 `search_files`

## 五、禁项

- 禁 `**`、`##`（段标题除外）、`|`、`$`、反斜杠、Markdown 表格
- 禁元话语：「扫描件」「OCR」「抽取」「切片」「文字层」「残片」
- 禁套话：「首先/其次/综上所述/总而言之/由此可见/赋能/抓手/闭环/值得注意的是」
- 正文不许出现「五步学习法」这六个字（只有段标题可以），也不许提前出现「易错」「例题」「自查」这些词
  （checker 按词切节，正文提前出现会把自己那一段算成 0 条）

## 六、自检（末行必须 `RESULT: PASS`）

```bash
python3 scripts/check_geo_jin_learn.py data/geography-jin/learn/_parts/L{NN}_<册>.json
```

常见红与修法：

| 报错 | 修法 |
|---|---|
| `字数 1180 ∉1200–2600` | 补一段实质分析（不要灌水句） |
| `五步节 322 ∉350–700` | 五条各写到 72–88 汉字 |
| `引文未逐字回表：…` | 回 textpack 重新挑一句，或删掉这处引文换一处 |
| `words 标注 1830 ≠ 实测 1834` | 按实测值改 `words` |
| `含元话语` | 改掉「教材扫描页/OCR」这类说法，直接讲内容 |

## 七、回报

一行式：`L{NN} 完成：8 篇 / checker PASS / 字数区间 1xxx–2xxx`，再附 ≤3 条「教材里没找到对应原文的点位」。

⛔ 不改技能库；⛔ 不动 `topics.json`/`questions.json`/别人的分片。

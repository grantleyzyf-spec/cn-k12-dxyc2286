## 教材原文从哪来

- 派单里 `lessons[].txt` 指向教材文本，**两种形态**：
  - **逐课切片**（路径在 `_shards/txt/<LID>_<册>/<topicId>.txt`）：已按单元名前定位，直接读；
  - **整册全文**（路径以 `整册全文.txt` 结尾，扫描件册属这种）：全文数万字，**不要通读**，
    用 `grep -n` 定位：
    ```bash
    F="<派单里的 txt 路径>"
    grep -n "章名关键字" "$F" | head        # 先找本章起始行
    sed -n '起,止p' "$F"                     # 再读该章 200–400 行
    grep -n "小节关键词" "$F" | head        # 定位本课时所在小节
    ```
    教材小节标题与派单 `name`（我们自己的课时名）**往往不同名**，按「章名 ＋ 小节序号/主题词」找，
    找到后读该小节 20–40 行，取其中成句的原文（定义、设问、例题引导句）作引文。
- 引文**逐字照抄**，不改写、不合并两句、不加省略号；每条 ≥8 汉字。
- **回表源有两份，任一命中即可**（checker 已按并集判）：`/tmp/mbsd/<tag>/ocr/all.txt`（旧版逐页 OCR）
  与永久 textpack（`…/数学/北师大版/<学段>/<册>/整册全文.txt`）。两份是**两次不同识别**，
  同一句常只有一份干净 ⇒ 不要为了「双源都命中」牺牲合格的句子，挑到哪份干净就用哪份。
  自己核验时把两份都读进来，`qnorm(引文) in src1 or in src2` 即可。
- 文本里 OCR 把数学符号读变形的（`犃`、`狓`、`犿`、`\f`、`�`、`Y`、`《`），按教材原意写回正确符号，句子结构不动；
  **残缺到读不成句的行直接跳过**，换同小节另一句。
- ⛔ 不写元话语（「扫描件」「OCR」「切片」「抽取」「残片」「文字层」）——把教材当读者手里的干净课本。
- 🔴 **五步学习法那节 350–700 汉字**：按「每条 60–65 汉字」写实测只有 316–339，必红；**每条按 72–80 汉字**才稳过。

## 输出结构

```json
{"book": "九年级上册", "lessons": [
  {"topicId": "mbs_j352", "title": "认识特殊平行四边形", "markdown": "## 一、开场：…\n\n…", "words": 1800}
]}
```

- `book` **只写册名**（`九年级上册` / `必修第一册` / `选择性必修第二册`），不带「北师大版」。
- `title` 用派单 `name` 原文。
- `words` = markdown 的汉字数（正则 `[\u4e00-\u9fa5]`），与 checker 现算值允许 ±50。

## 七段（`## ` 开头，顺序不可换，标题必须含给定关键词）

1. `## 一、开场：先说生活里的一件事` —— 2–3 个具体情形，末句点出本课要解决的问题
2. `## 二、课本原文说什么` —— **≥2 处** `> ` 引用块（每条 ≥8 汉字、逐字取自本课切片），
   每处引用后紧跟「这句话的意思是：……」
3. `## 三、费曼翻译：用大白话说清楚` —— 打比方 ＋ 一句话版本 ＋ 讲清机制；不喊口号
4. `## 四、例题精讲` —— **≥2 道**，写「例 1」「例 2」；每道必须有 `❌ 常见错法` 与 `✅ 正确做法`（全文 ❌/✅ 各 ≥2）
5. `## 五、易错点拨` —— 取该点 `misconceptions`（可能为空，就写本课最常见 2 个错法），说清为什么错、怎么自查
6. `## 六、五步学习法：这一课怎么吃透` —— **恰好 5 条**，`1. ` 起头，每条 ≥25 汉字，本节合计 **350–700** 汉字；
   五条依次落到 **锻炼 / 第一个知识点 / 积微 / 对标 / 杠铃**（五个词都要出现）
7. `## 七、方法锚与自查` —— 一句话方法锚 ＋ `- [ ]` 自查清单 **≥3** 条

## 硬性规则（checker 逐条判，红一条整片不合格）

- 全篇 **1200–2600 汉字**；用词按学段（初中/高中），不出超纲内容。
- 禁 Markdown 符号（`* _ # [ ] |`）与 LaTeX；公式写 `2^3`、`√2`、`x²`、`a²+b²=c²` 这类纯文本。
- 禁 HTML 标签、禁 Markdown 表格。
- 数字序号条目之间**必须空行**（`1. ` 与 `2. ` 紧邻会被判「序号条目粘连」）。
- 五步节之外的正文里不要堆 `1. 2. 3.` 列表，避免误判。

## 交付

文件 UTF-8 无 BOM。回复一行：`<LID> / <册> / <篇数> / 每篇汉字数区间 / checker 末行`。

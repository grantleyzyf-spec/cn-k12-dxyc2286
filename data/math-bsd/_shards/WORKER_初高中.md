# 北师大版数学 初/高中题库派单附加条款（与 WORKER.md 同时生效）

`WORKER.md` 的通用条款（每点 8 题、四题型、选项 4 个且文本互异、答案位 A/B/C/D 各 ≥15%、
`numeric` 的 `verify` 可 `eval` 复算且等于 `answer`、题干 ≥12 字、解析 ≥20 字、题干片内不重复、
`short-answer` 带 `keypoints`≥2、`topics[].description` 40–120 字、`mastery_criteria` 2–3 条）
全部照旧。**本文件只覆盖学段差异，冲突时以本文件为准。**

## 一、超纲边界

- **初中（grade 7–9）**：可用字母表示数、整式、方程与不等式、平面直角坐标系、函数（一次/反比例/二次）、
  三角形与四边形性质、相似与全等、勾股定理、圆的基本性质、统计图表与概率初步。可用 `π`、`√`、`°`。
  ⛔ 不用：三角函数（sin/cos/tan）的正式运算、对数、向量、导数、复数。
- **高中（grade 10–13）**：可用集合与逻辑符号（∈、⊆、∩、∪）、函数与映射、指数对数、三角恒等变换、
  向量、数列、导数及其应用、计数原理、概率分布。⛔ 不用大学内容（极限的 ε-δ、矩阵行列式、微积分定理证明）。

## 二、公式与符号写法（与小学不同）

- 只禁 **Markdown 记号**（`**`、`##`、反引号、`$`、表格竖线），**不禁数学符号**：
  `f(x) = 2x + 1`、`x²`、`√3`、`a/b`、`∠A`、`△ABC`、`≤ ≥ ≠ ∈ ⊆ ∪ ∩` 照写。
- 绝对值写成 `|x|`、`|k|` 可以（checker 已按成对绝对值放行）；⛔ 仍不许出现表格竖线。
- 幂用 `x²` 或「x 的平方」，⛔ 不用 `^`（Python 里是异或，`verify` 里幂必须写 `**`）。
- 分数写 `3/4` 或「四分之三」；根号写 `√2` 或「根号二」。
- 几何图形用文字描述（「如图，△ABC 中 AB = AC」），⛔ 不放图片、不用 TikZ。

## 三、难度与题量配比（每点 8 题）

- 初中：`basic 3 · standard 3 · hard 2`；高中：`basic 2 · standard 4 · hard 2`。
- 每点四种题型至少各 1 道；`numeric` 至少 2 道（初中计算题多，可到 3 道）。
- 高中解答型短答题的 `keypoints` 要写可判读的步骤要点（如「先求导」「令 f′(x)=0」「比较端点值」）。

## 四、`numeric` 与 `verify` 的写法

- `answer` 必须是**字符串**：`"7"`、`"0.375"`、`"-3/2"` 要写成 `"-1.5"`（浮点可复算）。
- `verify` 是纯 ASCII 算式，只用 `+ - * / ** ( )` 与数字：如 `answer:"24"`, `verify:"(-2)**3+5*8"`。
- 答案带单位的题（如「面积 12 cm²」）→ 用 `fill` 而不是 `numeric`，`answer` 只填数字。
- 含无理数/根的答案不要用 numeric（浮点比对会炸），改成 `fill` 写精确形式（`2√3`）。

## 五、题号与 id

- 题号 `<前缀>_q<片2位><流水4位>`，片号由派单给定（如 S31 → `mbs_q310001` 起）。
- `topicId` 只能用本片 spec 里的 id（初中 `mbs_j###`、高中 `mbs_h###`），⛔ 不许自造、不许挂到小学 `mbs_p###`。

## 七、工位纪律（踩过的坑，照做）

- ⛔ **不要用 `search_files`** 找分片：仓库树很大，它会 420 s 超时并连累同批其它子代理。
  分片路径就是 `data/math-bsd/_shards/<册>_第<N>单元.json`，直接 `read_file` 即可；册名/单元号由派单给定。
- 每道题都必须有 `answer` —— `short-answer` 也要（schema 必填），缺了 checker 会逐题报红。
- `choice` 的 `choices` 必须是 object 数组，与 `options` 同值（`d["choices"] = d.get("options", [])`），
  ⛔ 不要塞字符串数组。
- `verify` 里不能用全角负号 `－` 或全角括号（`float()` 会解析失败），必须 ASCII。
- 20 点以上的大分片**分批生成再合并**写盘（每批 5–8 点），一次性写完容易在 70 s 内被卡住。
- 交回前把 checker 跑到末行 `PASS` 并把整段失败清单清零；父代一定会重跑，自报不算。

# 历史试卷讲解合同（K 系列，117 卷）

## 你只做一件事
读你的派单 `data/history/_lecture_shards/KNN.json`（2 卷，卷面 `path` 已给）→ 每卷写一份讲解 JSON 到 `out_dir` → 自检到 PASS。

## 1 产物形状
```json
{"examId":"his_exam_q7a_midA","book":"七年级上册","paper":"期中测试卷A","kind":"mid",
 "words":5200,"markdown":"## 这份卷在考什么\n…"}
```
`words` = `markdown` 汉字数（`[\u4e00-\u9fa5]`），误差 ≤6。先 read_file 卷面 JSON 逐题读，不许凭印象编题号。

## 2 六段（标题逐字，顺序不可换）
```
## 这份卷在考什么
## 考点地图
## 逐题精讲
## 整卷复盘
## 五步学习法
## 自查清单
```

## 3 硬口径
1. 全文汉字：**初中 4000–7800 / 高中 4500–8800**（按派单 `stage`）。
2. **逐题覆盖**：卷面每一题都要出现「第 N 题」，一题不漏（初中 24 题、高中 21 题）。
3. **逐题三要素**：每题写「思路」「易错」，「关键一步」出现次数 ≥ 题数×0.6。
   写法：`**第 3 题（2 分）** 思路：……；关键一步：……；易错：……`
4. 题分标注必须等于卷面该题 `score`。
5. **考点地图**：逐题列「第 N 题｜知识点｜分值」，末行写「最重三考点：…」；⛔ 禁 Markdown 表格。
6. **五步学习法**：五条短语逐字（每天锻炼一个小时／扎实掌握第一个知识点／能积微者速成／运用对标思维突破学习困境／运用杠铃法则缓解学习疲劳），各自成段，本节 250–750 汉字。
7. 自查清单 `- [ ]` ≥6 条。
8. ⛔ 禁拉丁字母（写「公元前 221 年」「千米」）；⛔ 禁 AI 味词（首先／其次／综上所述／总而言之／由此可见／赋能／抓手／闭环／值得注意的是）；⛔ 禁「分五段」类表述。
9. 材料题按卷面 `scoreRule` 分步讲给分点（各步之和 = 题分）。

## 4 自检
```bash
/usr/bin/python3 scripts/check_exam_lecture.py "<你写的讲解.json>" --subject history
```
到「不合格 0」。两卷都要 PASS。

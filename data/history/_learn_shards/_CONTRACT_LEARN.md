# 历史学层精讲合同（HL 系列，224 篇）

## 你只做一件事
读你的派单 `data/history/_learn_shards/HLNNN.json` → 逐课写 `out` 指定的 `learn/_parts/HLNNN.json` → 自检到 PASS。

## 1 产物形状（照派单）
```json
{"taskId":"HL001","book":"七年级上册","lessons":[
  {"topicId":"his_p001","title":"…","chapter":"…","book":"七年级上册","words":1850,"markdown":"…"}]}
```
`words` = `markdown` 汉字数（`[\u4e00-\u9fa5]`），误差 ≤10。

## 2 七段（标题逐字，顺序不可换）
```
## 一、开场
## 二、课本原文
## 三、费曼翻译
## 四、例题精讲
## 五、易错点拨
## 六、五步学习法
## 七、方法锚与自查
```

## 3 硬口径
1. 全篇 **1200–2800 汉字**；五步节 **350–900 汉字**。
2. **课本原文 3 处**（都用 `> ` 引用块，每处紧跟「这句话的意思是……」）：
   - **1 处课标原文**：逐字取自该课的 `standards[].quote`（学习层 checker 硬性要求至少 1 处等于课标原文）；
   - **2 处教材原文**：从派单的 `txt` 里 `grep` 到整句后**逐字照抄**（⛔ 不许改写、不许自造）。
   `txt` 为 null 的册（九年级下册，教材库缺 PDF）改为「1 处课标语 ＋ 2 处课标语或跨册同主题史料」，并在汇报里注明。
3. 例题 **2 道**，每道都有 `❌` 错解和 `✅` 正解（用这两个符号本身）。
4. 五步学习法五条**逐字**：每天锻炼一个小时／扎实掌握第一个知识点／能积微者速成／运用对标思维突破学习困境／运用杠铃法则缓解学习疲劳；每条独立成段，条间空行。
5. 自查清单 `- [ ]` **≥3 条**。
6. ⛔ 禁 AI 味词：首先、其次、综上所述、总而言之、由此可见、赋能、抓手、闭环、值得注意的是。
7. ⛔ 禁拉丁字母（写「公元前」「千米」「摄氏度」）；⛔ 禁 Markdown 表格与 `**`。
8. ⛔ 正文不出现「扫描件」「OCR」「抽取」这类元话语；不解释图片。

## 4 内容口径
- 历史课：时间、人物、事件、因果、史料实证；讲清「为什么会发生」「影响是什么」。
- 一课只讲本课（`title` 所给）内容，不串到邻课。

## 5 自检
```bash
/usr/bin/python3 scripts/check_history_learn.py <你的 out 文件>      # 到「不合格 0」
/usr/bin/python3 scripts/verify_history_quotes.py <你的 out 文件>    # 引文回表，必须「失配 0」
```

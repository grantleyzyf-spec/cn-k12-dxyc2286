# 苏教版高中化学 知识点描述工位合同（按册分派）

## 0. 产物

`data/chemistry-sujiao/_desc/<册名>.json`，册名与派单一致（`必修第一册` / `必修第二册` / `选择性必修第一册` / `选择性必修第二册` / `选择性必修第三册`）：

```json
{"book":"必修第一册",
 "units":[
  {"no":1,"name":"物质的分类及计量","domain":"物质的组成与结构",
   "lessons":[
     {"name":"物质及其反应的分类","description":"…40–120 汉字…",
      "c1":"…≥10 汉字…","c2":"…≥10 汉字…"}]}]}
```

`units[].no` / `name`、`lessons[].name` **必须逐字照抄** `data/chemistry-sujiao/_structure.json`（同一册部分），一个不多一个不少，顺序一致。

## 1. 字段口径

- `description`：40–120 汉字。写清「本课时讲什么 + 学生要建立的核心概念/方法 + 与前后课时的关系」，句子通顺，不写「本节课我们将学习」这类空话。
- `c1` / `c2`：掌握标准，各 ≥10 汉字，可观察可测（「能写出…」「能判断…」「能解释…」），两条不要同义反复。
- `domain` 只能取五个值之一（按课标内容领域，逐专题判定）：
  `物质的组成与结构` / `物质的化学变化` / `物质的性质与应用` / `科学探究与化学实验` / `化学与社会·跨学科实践`
- 化学式、离子符号、方程式按教材原样书写（如 `SO₄²⁻`、`NH₄⁺`），不用 LaTeX、不用 `**`、不用 Markdown。

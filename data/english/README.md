# 英语学科知识点数据库

## 文件说明

### topics.json (204个知识点)
- **小学(3-6年级)**: 59个知识点
- **初中(7-9年级)**: 74个知识点  
- **高中(10-12年级)**: 71个知识点

ID格式:
- 小学初中: `eng_p001` - `eng_p133`
- 高中: `eng_h001` - `eng_h071`

每个知识点包含:
- id: 唯一标识符
- name: 知识点名称(英文)
- subject: "english"
- grade: 年级(3-12)
- semester: "fall"或"spring"
- chapter: 教材章节(人教版PEP/Go for it!/人教版2019)
- description: 能力描述(中文)
- tags: 标签分类
- prerequisites: 先修知识点ID列表
- curriculumRef: 课标参考

### dependencies.json (209条依赖关系)
- from: 先修知识点ID
- to: 后续知识点ID
- 无环依赖图

### questions.json (204道诊断题)
每个知识点1道诊断题:
- topic_id: 对应知识点ID
- question: 诊断问题
- options: 4个选项(A/B/C/D)
- difficulty: "basic"
- type: "diagnostic"

# 鄂教版数学 · 学层精讲工位（WORKER_LEARN.md）

## 输入（只读）
`data/math-ejiao/_learn_shards/<topicId>.json`
- `title`：课时名；`book`／`chapter`／`unit`／`grade`：归属
- `page`：教材页码；`textbook_excerpt`：该页前后 3 页的**教材 OCR 原文**（引文只能从这里逐字摘）
- `standards`：课标条目（`quote` 可作课标依据，但不计作「课本原文」）
- `outPath`：你要写的文件

## 产出（只写这一个文件）
`data/math-ejiao/_learn_out/<topicId>.json`
```json
{"topicId": "<派单 topicId>", "title": "<课时名，原样>",
 "markdown": "……整篇 Markdown……", "words": <实测汉字数>}
```
`words` 必须等于 `len(re.findall(r"[\u4e00-\u9fa5]", markdown))` 的结果。

## markdown 的七段结构（小标题文字必须出现，顺序固定）
```
# <课时名>

## 一、开场：<一个生活场景的小标题>
（150–250 字真实场景，把本课的数学问题问出来）

## 二、课本原文说了什么
> <教材原句，≥12 汉字，逐字摘自 textbook_excerpt>
这句话的意思是：……
> <第二处教材原句，≥12 汉字>
这句话的意思是：……
（再补 1–2 处也行；**块引用 ≥2 处且必须能在教材 OCR 里逐字命中**）

## 三、费曼翻译
（把本课概念用初二学生听得懂的话重讲一遍，可打比方，200–350 字）

## 四、例题
**例1** …（题目＋解题步骤＋❌常见错解 ＋ ✅正确做法）
**例2** …（同结构；两例难度递进）

## 五、易错点拨
- 错误一：……（为什么错、怎么防）
- 错误二：……

## 六、五步学习法
① 每天锻炼一个小时：……
② 扎实掌握第一个知识点：……

④ 运用对标思维突破学习困境：……
⑤ 运用杠铃法则缓解学习疲劳：……

## 七、自查
- [ ] ……
- [ ] ……
- [ ] ……
```

## 硬性指标（checker 逐条卡）
| 项 | 要求 |
|---|---|
| 汉字数 | **1000–2000**（目标 1400–1800，超 1950 就删修饰句） |
| 七个小标题 | 开场／课本原文／费曼翻译／例题／易错／五步学习法／自查 一个不能少 |
| 块引用 `> ` | ≥2 处，每处 ≥8 汉字，去标点后须在教材 OCR 全文命中 |
| 例题 | ≥2 道，写成 `**例1**` `**例2**` |
| 易错 | ≥2 条（`- ` 起行） |
| 自查 | ≥3 条 `- [ ]` |
| 五步 | 五个关键词（锻炼／第一个知识点／积微／对标／杠铃）都要出现 |
| 禁 | LaTeX `$…$`、HTML 标签、Markdown 表格（`|…|` 行） |

## 写法纪律
1. 数学符号照写：`+ − × ÷ = ≤ ≥ √ π`、`x²`、`sin x`、`aₙ`（下标可直接写 a 下标 n 或 a_n，全文统一）；**禁 Markdown 记号和 LaTeX**。
2. 引文**只能**从 `textbook_excerpt` 里逐字摘（OCR 有错字就挑没错字的句子）；摘不到两句就换更短的句子，不许自造「课本原话」。
3. 例题要真算：答案与步骤必须自洽；用到 `textbook_excerpt` 里的情境更好。
4. 语气：像一位耐心的数学老师跟学生当面讲，不用「本课旨在」「综上所述」这类套话；不出现「课本第 X 页」之外的教材页码引用。
5. 只写本课时内容，不写别的章。

## 自检（必做）
```bash
python3 data/math-ejiao/_scripts/check_learn_ej.py --shard <topicId>
```
末行必须是 `PASS`。FAIL 按提示改（字数/引文命中/例题数/自查条数）后重跑。

## 回复格式（一行）
`<topicId> 完成：汉字 N；PASS`

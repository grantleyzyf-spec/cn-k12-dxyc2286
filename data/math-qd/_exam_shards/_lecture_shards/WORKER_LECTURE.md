读派单 `data/math-qd/_exam_shards/_lecture_shards/<Knn>.json`（含 `book / stage / grade / out_dir / exams[]`，每卷给 `paper / examId / kind / path / topicNames`），
为**每份卷**写一份讲解，落到 `out_dir/<paper>.json`，并跑自检到 PASS：

```bash
cd ~/Desktop/cn-k12-dxyc2286
python3 scripts/check_math_qd_lecture.py data/math-qd/exam_lectures/<册>/<paper>.json
```

⛔ 只写派单里那几份讲解；不改题库、卷面、学层、别人的分片。

## 先读卷面
`exams[]` 里的 `path` 就是源卷（含 `sections[].items[]`：`no / type / stem / options / answer / score / analysis / topicIds`）。
讲解必须**逐题对得上卷面**：题号、题型、分值、答案都要与卷面一致。

## 输出结构
```json
{"examId": "mhj_exam_b1_u01", "book": "青岛版必修第一册", "paper": "<卷名>", "kind": "unit",
 "markdown": "# <卷名> · 讲解\n\n## 一、这份卷在考什么\n…", "words": 5200}
```
`words` = markdown 汉字数（`[\u4e00-\u9fa5]`，允许 ±6）。

## 六段（标题逐字，顺序固定）
1. `## 一、这份卷在考什么` — 满分/时长/大题结构（每大题几小题多少分）；难度分布（基础/中档/较难 各几题多少分）；这张卷想筛出什么能力
2. `## 二、考点地图` — 覆盖的课时点逐条列出（用 `topicNames` 的正式名），每条说「本卷考了哪几题、考到什么深度」
3. `## 三、逐题精讲` — **每道题都要出现 `第 N 题`**，每题四要素：
   - `**第 N 题（X 分）**` 行首（分值写卷面真实分数）
   - `思路：`（怎么切入、为什么这么想）
   - `关键一步：`（真正决定成败的那一步，至少 60% 的题要有）
   - `易错：`（这题最常掉进的坑）
   - 选择题要写清错项为什么错；解答题写完整步骤链 + 得分点
4. `## 四、整卷复盘` — 分数分布回看、时间分配建议、按错的题型分类给出补强顺序
5. `## 五、五步学习法` — **恰好 5 条**，标签逐字用：
   `**每天锻炼一个小时**` / `**扎实掌握第一个知识点**` / `**能积微者速成**` / `**运用对标思维突破学习困境**` / `**运用杠铃法则缓解学习疲劳**`
   本节合计 250–750 汉字；**每条标题后必须空一行**再写正文
6. `## 六、自查清单` — `- [ ]` ≥6 条，可勾可验

## 硬性规则
- 小学卷 3500–7200 汉字、高中卷 4500–8800 汉字（苏教本批只有小学与高中）。
- ❌ LaTeX（`$`、`\frac`、`\sqrt`、`\times`）、HTML 标签、Markdown 表格、`分五段/五个部分` 之类旧口径说法。
- 数字与单位之间空一格（写 `3 m`，不写 `3m`）。
- 公式用纯文本：`x^2`、`√2`、`x²`、`log_2 8`、`sin 30°`。
- 讲解语气面向学生，直陈过程与原理，不写「本题解析如下」这类套话、不写元叙述。

## 交付
文件 UTF-8 无 BOM；回复一行：`Knn / 卷数 / 每卷汉字数 / checker 末行`。

## 青岛版专有两条

1. **教材页不必回表卷面**（讲解不需要引教材原文），但**卷面题干里的情境名**（如「快乐的课堂」「探访果蔬博览会」）要照抄，不要改写成通用说法。
2. **小学卷 31/36 题较多**：小学 1-2 年级 36 题、3-6 年级 31 题，逐题块一个都不能少（checker 按卷面题数比对），字数带按小学 3500–7200 汉字。

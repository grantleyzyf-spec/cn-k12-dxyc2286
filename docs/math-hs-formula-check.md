**结论与口径（写进 docs 与后续作业规范）**

1. **双 OCR 引擎都不能用于公式**：30 页抽样里「数字一致率」中位数 0.60、最低 0.23，`Σ`、上下标、分式、`＋`、绝对值竖线系统性出错，且会出现整行反序。⇒ 任何公式、例题数值、答案，**不得**从 `data/math/ocr_highschool/*.txt` 抄。
2. **OCR 文本的适用边界＝文本级检索**：小节名、栏目名、术语、「思考/探究」题干的中文都可放心检索（中文二元组覆盖 0.61–0.91）。
3. **公式级核对的正确通道是视觉模型逐页读**（本轮 3 页全部读对，含 ∑ 上下标、分式、矩阵式分段函数）。成本≈每页 1 次调用，可按需抽查，不必全册跑。
4. 已知仍需逐页核的高风险位置：例题解答中的数值、`Σ`/`√`/分式密集的推导页、表格里的统计量（`f_0`、`P(Y=1|X=0)` 之类）。

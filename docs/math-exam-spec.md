# 数学单元卷 / 期中卷 / 期末卷：内容层工位说明书（V1.0）

> 目标：给数学 19 册（小学 9 + 初中 5 + 高中 5）配套**原创**单元测试卷、期中 2 套、期末 2 套，
> 每卷另出「参考答案与评分标准」。写手只交 JSON，docx 由父工位统一生成。

## 1 输入

| 材料 | 路径 |
|---|---|
| 本册课时清单（单元 / 课时名 / 印刷页） | `data/math/ke_json/_toc/<册>.txt` |
| 本册课时级知识点（含 id，命题必须挂 id） | `data/math/topics.json`（chapter 形如 `<册> <单元> <单元名> · <课时名>`） |
| 教材 PDF | 小学 `…/数学/小学/人教版/*.pdf`、初中 `…/数学/初中/人教版/*.pdf`、高中 `…/数学/高中/人教版（A版）/*.pdf` |
| 公式权威来源（高中） | `docs/math-hs-formula-ledger.md`（OCR 不可信，公式一律取台账） |

## 2 输出

`data/math/exams/<册>/<卷名>.json`，卷名固定为：
`第一单元测试卷` / `期中测试卷A` / `期中测试卷B` / `期末测试卷A` / `期末测试卷B`

```json
{
  "book": "七年级上册", "kind": "unit", "term": "上册", "grade": 7, "stage": "初中",
  "paper": "第一单元测试卷", "duration": 90, "fullScore": 120,
  "scope": ["第一单元 有理数"],
  "sections": [
    {"title": "一、选择题", "rule": "每小题 3 分，共 30 分",
     "items": [
       {"no": 1, "score": 3, "type": "choice", "difficulty": "basic",
        "topicIds": ["mat_p1234"], "stem": "题干（≥12 字）",
        "options": [{"label":"A","text":"…"},{"label":"B","text":"…"},
                    {"label":"C","text":"…"},{"label":"D","text":"…"}],
        "answer": "B", "analysis": "解析（≥20 字，讲清为什么）"}
     ]}
  ]
}
```

- **解答题**（`type` 为 `solve`）用 `answer` + `analysis` + `scoreRule`：
  `scoreRule` 是分步给分清单（如 `["正确设未知数 2 分","列出一元一次方程 4 分","解得 x=5 并检验 2 分"]`），
  **各步分值之和必须等于该题 `score`**。
- **多选题**（高中，`type` 为 `multi`）：`answer` 写全部正确选项（如 `"ABD"`），
  `scoreRule` 写 `["全部选对得 5 分","部分选对得部分分","有选错得 0 分"]`。
- 计算/填空题若答案是数值，可给 `verify`（如 `"(-3)+5"`），供机检复算。

## 4 命题铁律

1. **原创**：不得照抄教材例题/习题原题，也不得复用 `data/math/questions.json` 里已有的 9865 道题；
   素材要**变式**（换情境、换数据、换问法），机检会算与题库的相似度。
2. **覆盖**：单元卷的 `topicIds` 必须**覆盖本单元全部课时点各至少 1 次**；期中卷覆盖前半学期各单元、
   期末卷覆盖全册各单元且每单元至少 2 题。
3. **算对**：所有数值答案自己复算；高中公式以公式台账为准。
4. **难度配比**：约 basic 50–60%、standard 30–40%、hard 10–15%（卷末压轴 1–2 题用 hard）。
5. **不超纲**：只考本卷范围（单元卷不考后续单元；期中卷不考后半学期；期末卷不考他册）。
6. **答案完整**：每题必须有 `answer` 与 `analysis`；解答题必须有 `scoreRule` 且分值和 = 题目分值。

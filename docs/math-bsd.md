# 数学（北师大版，`math-bsd`）

北师大版小学数学知识图谱。与「数学（`math`，人教版）」并列的**独立学科**：`subject` 不同、
`id` 前缀不同（`mbs_`），页面按学科切换即可，两版互不干扰。

## 1. 覆盖与规模（当前切片：一年级上册）

| 项目 | 数量 | 说明 |
| --- | ---: | --- |
| 知识点 | 31 | 一年级上册 5 个单元的全部教材课时（每课时 1 点） |
| 先修边 | 26 | 同单元课时顺次 `hard` + 册际衔接 `soft` |
| 诊断题 | 248 | 每点 8 题（choice 74 · fill 57 · numeric 59 · short-answer 58） |
| 课标条目 | 7 | `mbs-2022:1.{SD,TX,TJ,ZH}.NN`，全部挂第一学段引文 |
| 根节点 | 5 | 每个单元的第 1 课时，均带 `root_reason` |
| 领域分布 | 4 | 数与代数 20 · 图形与几何 5 · 统计与概率 4 · 综合与实践 2 |

## 2. 口径（与 `data/math` 人教版一致）

1. **一个教材课时 = 一个知识点**（课时级）；习题课、巩固练习、回顾与思考、单元整理不成点
   （建库时已剔除 51 条，见 `scripts/build_bsd_skeleton.py` 的 `SKIP_LESSON`）。
2. `chapter` = `<册> 第<中文>单元 <单元名>`，页面册名从 `chapter` 首段派生；
   `grade` 1–6（小学）、7–9（初中）、必修一=10 / 必修二=11 / 选必一=12 / 选必二=13（高中）；
   `semester` 上册=上、下册=下。
3. `domain` 只用课标四领域（数与代数 / 图形与几何 / 统计与概率 / 综合与实践）；
   关键词规则覆盖不到的单元用 `UNIT_DOMAIN_OVERRIDE` 人工裁定（如「整理与分类」→统计与概率、
   「测量（一）(二)」→图形与几何）。
4. 题库：每点 8 题，`choice/fill/numeric/short-answer` 四类齐备，`numeric` 的 `verify` 必须
   可 `eval` 复算且等于 `answer`，答案位 A/B/C/D 各 ≥15%，题干 ≥12 字、解析 ≥20 字、全域不重复。

## 3. 结构源（为什么不是「凭印象写单元」）

| 源 | 路径 | 用在哪 |
| --- | --- | --- |
| 分课时教学设计 docx（权威） | `中小学教材/各学科分课时设计/数学/北师大版/<学段>/<册>/` | 文件名自带「第N单元 X·第K课时 名」与「全册共N课时」，**上册 6 册（小学）+ 3 册（初中）** |
| 大单元整体教学设计 docx（兜底） | `1.0标准合集/小学数学/北师大版小学数学大单元整体教学设计`（83 份）、`中小学教材/数学/<学段>/北师大版/大单元整体教学设计` | 取「十五、教-学-评一致性课时设计」段的课时名，覆盖全部 21 册（含下册） |
| 教材 PDF | `中小学教材/数学/<学段>/北师大版/*.pdf` | 正文核对；小学 9 册、初中 5 册、高中 4 册有 PDF（四上/五上/六上/九上/高中四册有文字层，其余为扫描版） |

对账（`scripts/scan_bsd_structure.py` 打印）：册级「各单元课时之和 vs 分课时 docx 声明的全册课时」、
单元级「解析条数 vs（共M课时）」、单元号 1..N 连续性。

## 4. 课标引文口径（重要：不用 OCR 版）

- 引文源＝`…/2025修订课程标准TXT /义务教育/3.《义务教育数学课程标准·日常修订版》(2022年版2025年修订)（docx转换）.txt`
  （由官方 **docx** 直接转换，100 684 字符）。
- ⛔ **不要用同目录的 OCR 版 TXT**：它把「减法」识别成「袜法」、「熟练」→「郊练」、「时间」→「时问」，
  引文会带错字。人教版 `math` 的旧引文回表用的就是 OCR 版，属历史遗留，不在本学科沿用。
- 引文库（第一学段 9 条）在 `scripts/attach_bsd_std.py` 的 `POOL` 里**人工裁定**，每条都做
  「去空白后必须是课标原文子串」自检；知识点按课时名+单元名的规则表 `RULES` 归条，
  规则命中判 `partial`，跨领域兜底判 `inferred`。

## 5. 已知缺口

1. **只上线了一年级上册**（31 点 / 248 题）。小学其余 11 册、初中 5 册、高中 4 册的骨架已就绪
   （`data/math-bsd/_skeleton_小学.json`：84 单元 / 562 点 / 489 边），缺的是分片题库。
2. **九下无结构源**：北师大版九年级下册既无分课时 docx 也无大单元 docx（教材 PDF 也缺），
   该册需要新教材到位后再建。
3. **第二、三、四学段引文库未建**：`POOL` 目前只有第一学段 9 条；扩到 3–9 年级时必须按同一
   docx 源补 第二学段（3–4）/第三学段（5–6）/第四学段（7–9）的引文，否则 lesson 会全部退化成 `inferred`。
4. 教材 PDF 里 一上~三下、七上~八下 为扫描版（无文字层），本轮未做 OCR；结构来自 docx，正文核对待补。

## 6. 自检

```bash
python3 scripts/validate.py math-bsd            # 结构/引用
python3 scripts/test_math_bsd.py                # 48 项不变量（含 quote 逐字回表；无 TXT 时跳过）
python3 scripts/scan_bsd_structure.py --stage 小学    # 结构盘点与三重对账
python3 scripts/build_bsd_skeleton.py --stage 小学 --scan /tmp/bsd_小学.json \
        --out data/math-bsd/_skeleton_小学.json      # 骨架重建
python3 scripts/check_bsd_bank.py <spec> <bank>       # 单个分片题库校验
python3 scripts/merge_bsd_bank.py                     # 合并 _bank → topics/questions
```

## 7. 页面用法

- 学科下拉新增「📐 数学（北师大版）」；册次下拉从 `chapter` 派生（当前只有「一年级上册」）。
- 深链：`explore/?subject=math-bsd&book=一年级上册#mbs_p001`。

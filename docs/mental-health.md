# 心理健康（`mental-health`）

心理健康按「数据模型 → 课标回表 → 题库 → 自检 → 文档 → 站点 → CI」建库，口径与其它学科一致（见 [docs/math.md](math.md)、[docs/chinese.md](chinese.md)）。本学科是**首次建库**（数据源为北师大版《心理健康》系列与《中小学心理健康教育课程标准(2026年)》）。

## 1. 规模

| 项目 | 数量 | 说明 |
| --- | ---: | --- |
| 知识点 | 380 | 单元级 96（上位/展示）＋ 课时级 284（可诊断） |
| 先修边 | 568 | `hard` 479（单元→课、课内顺次）· `soft` 89（册际衔接、同素养纵向递进） |
| 诊断题 | 2752 | 单元点 ≥5 题、课时点 ≥8 题；choice 1945 · fill 469 · short-answer 338 |
| 课标条目 | 25 | 五素养 × 五学段，全部被引用（25/25，`confidence: exact`） |
| 课标引文 | 380 条 | 每条知识点挂 1 条原文句，逐字回表 100% |
| 根节点 | 16 | 每册首单元（册际软边未连的册头），均带 `root_reason` |

## 3. 课标对齐

- 依据：《中小学心理健康教育课程标准(2026年)》（`2025修订课程标准/` 下同名 docx），已落成可回表 TXT 快照：
  `~/Desktop/中小学教材/2025修订课程标准TXT /义务教育/《中小学心理健康教育课程标准》(2026年).txt`（252 行）。
- **25 条内容要点句（五素养 × 五学段）全部逐字回表命中（25/25）**；知识点引文一律取所在学段、所在素养的原句片段，`sourceLine` 按快照定位（当前 23–79 行）。
- 五大核心素养（课标原文）：**自我意识 · 情绪管理 · 人际交往 · 学会学习 · 生命与社会适应**。
- 素养归属规则：单元按「单元名 + 课名」关键词定素养，14 个关键词法打不住的单元逐条人工裁定（见 `build_xl_skeleton.py` 的 `OVERRIDE`）；每册每单元只归一个素养，故 `domain` 是单元级属性、课时级继承。

内容口径：情境取自课堂、家庭、同伴、考试、手机等学生真实生活；只使用五个素养词；**不作医学诊断**（涉及持续困扰统一写「向心理老师或专业机构求助」）；不写空泛口号。

## 5. 生成管线（可复算）

1. **盘点教材**：扫 `各学科分课时设计/心理健康/北师大版/{小学,初中,高中}` 的 docx 文件名 → 册／单元／课三级结构（18 册 / 96 单元 / 284 课）。
2. **骨架**：`build_xl_skeleton.py` → `data/mental-health/_skeleton.json` + `_deps.json` + `_shards/S01–S18.json`（每册一份派单）。
3. **分片写内容与题**：18 个写手按 `_shards/WORKER.md` 契约各写 `_bank/Sxx.json`，每片必须过 `check_bank.py Sxx`（覆盖完整、题量、4 选项、三档难度、答案位均衡、无违禁词）。
4. **合并**：`merge_xl.py` → `topics.json` / `questions.json` / `dependencies.json`（只保留 schema 允许字段，回填 `sourceLine`）。
5. **门禁**：`validate.py mental-health` + `test_mental_health.py`（35 项）。

## 6. 已知缺口（如实登记）

- **五年级上／下册只有单元点**：本机这两册只有「单元合集」分课时 docx、无逐课分课时，`课时级知识点缺失`（各 3 点）。
- **三年级上册 12 课、四年级下册 8 课**：教材课次未齐全（正常应为 18 课），课时点相应偏少。
- **只建北师大版**：人教版／其他省编心理健康教材未建。
- **单元点与课时点同池编号**：`mhe_p###`/`mhe_h###` 按册序连续编号，`level` 字段区分层级；若后续要按层级分前缀，需全库改 id 与引用。
- **题量偏薄**：2752 题 / 380 点 = 7.2 题/点（单元点 5、课时点 8 刚好达线，无冗余），后续可加易错题与情境变式。

## 7. 自检与页面

```bash
python3 scripts/validate.py mental-health     # 结构与引用
python3 scripts/test_mental_health.py         # 35 项不变量（缺课标快照时自动跳过回表 2 项）
python3 data/mental-health/_shards/check_bank.py S01   # 单片分片闸门（写手用）
```

页面：`index.html?subject=mental-health`；册次下拉为一年级上–下 … 高三（grade 10–12 显示为册名，不出现「十X年级」）。

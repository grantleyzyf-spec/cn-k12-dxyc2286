# 心理健康（`mental-health`）

心理健康按「数据模型 → 课标回表 → 题库 → 学层精讲 → 单元测评卷 → 自检 → 站点 → CI」建库，口径与其它学科一致（见 [docs/math.md](math.md)、[docs/chinese.md](chinese.md)）。数据源为北师大版《心理健康》系列（18 册）与《中小学心理健康教育课程标准（2026 年）》。

## 1. 规模

| --- | ---: | --- |
| 知识点 | 413 | 单元级 96（上位/展示）＋ 课时级 317（可诊断） |
| 先修边 | 626 | `hard` 538（单元→课、课内顺次）· `soft` 88（册际衔接、同素养纵向递进） |

## 3. 课标对齐

- **25 条内容要点句（五素养 × 五学段）全部逐字回表命中（25/25）**；413 个知识点各挂 1 条本学段本素养的原句，`sourceLine` 按快照定位（当前 23–79 行）。

| 卷题原创性 | 卷题与题库同册题 6-gram 相似度最高 **0.295**（阈值 0.85） |

内容口径：情境取自课堂、家庭、同伴、考试、手机等学生真实生活；只使用五个素养词；**不作医学诊断**（涉及持续困扰统一写「向心理老师或专业机构求助」）；不写空泛口号；测评卷不做期中/期末，只做单元素养测评，避免心理学科被考试化。

## 5. 学层精讲（`data/mental-health/learn/`）

- 317 篇，按册汇总为 `learn/<册>.json`（`items[{topicId,title,han,md}]`）＋ `learn/index.json`（册数/篇数/汉字总量）。
- 七段固定结构：先说生活里的一件事 → 课标和课本怎么说（**逐字引用课标原句**并接「这句话的意思是……」）→ 用大白话讲清楚（费曼式机制拆解）→ 两个情境演练（❌/✅ 对照）→ 容易踩的坑 → 五步学习法（五条固定序逐字，且逐条落到本课做法）→ 方法锚与自查（`- [ ]` ≥3）。
- 每篇 1200–2600 汉字（篇均 1,856），总量 588,284 汉字；覆盖全部 317 个课时点，无缺篇、无重复。
- 门禁：`learn/_shards/check_learn.py L001…L080`（逐片，写手用）；`scripts/test_mental_health.py` 内另有全量校验。

## 6. 单元测评卷（`data/mental-health/exams/`）

- 18 卷，落成 `exams/<册>.json` ＋ `exams/index.json`；每题带 `topicId`、所属单元、解析、分值；简答带 3 条评分要点（合分 = 题分）；整卷带 `blueprint`（题号 → 单元 → 素养 → 能力层级 → 分值）。
- 覆盖率：3 单元册每单元 ≥4 题、10 单元册每单元 ≥2 题，全部达标。
- 门禁：`exams/_shards/check_exam.py E01…E18`（题量/满分/时长/覆盖/topicId/选项/rubric 合分/**与题库相似度 <0.85**）。

## 7. 生成管线（可复算）

1. **盘点教材**：扫 `各学科分课时设计/心理健康/北师大版/{小学,初中,高中}` 的 docx 文件名 → 册／单元／课三级结构（18 册 / 96 单元 / 317 课）。文件名有三种形态（带「第 N 课」、只给课时名、单元名自带 `·`），解析器都覆盖。
2. **骨架**：`build_xl_v3.py` → `_skeleton.json` + `_deps.json` + `_shards/S01–S28.json`。**补点不重编既有 id**（旧 380 点 id 原样保留，新增 33 点从 `mhe_p291` 起续编），避免题库 / 学层 / 测评卷全部失联。
3. **分片写手**：题库 21 片（`_shards/WORKER.md`）、学层 80 片（`learn/_shards/WORKER_LEARN.md`）、测评卷 18 片（`exams/_shards/WORKER_EXAM.md`），每片必须过对应 `check_*.py`。
4. **合并**：`merge_xl.py`（题库）＋ `merge_xl_learn_exams.py`（学层 / 测评卷）。
5. **门禁**：`validate.py mental-health` + `test_mental_health.py`（42 项）。

## 8. 已知缺口（如实登记）

- **五上只有 8 个课时**（该册分课时 docx 只到 8 个课时）、**四下只有 8 课**、**三上 19 课**——课时点按实际素材建，未虚构。
- **只建北师大版**：人教版与其他省编心理健康教材未建。
- **单元点与课时点同池编号**：`mhe_p###`/`mhe_h###` 按册序连续编号，`level` 区分层级；若日后要按层级分前缀，需全库改 id 与全部引用（题库 3016 题、学层 317 篇、测评卷 360 题）。
- **学层逐段字数**：门禁只卡总量 1200–2600；契约里的「段建议区间」在部分篇目（尤其第三段费曼段）会被写成 400–500 汉字，属可读性取舍，不影响门禁。
- **无期中/期末卷**：心理学科不做阶段考试，只做单元素养测评（18 卷）。
- **题量无冗余**：3016 题 / 413 点 ≈ 7.3 题/点（单元点 5、课时点 8 刚好达线），后续可加易错题与情境变式。

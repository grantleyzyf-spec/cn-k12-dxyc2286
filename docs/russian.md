# 俄语（`russian`）

俄语按「数据 → 课标回表 → 题库 → 自检 → 文档 → 页面口径 → CI」七件套收口，口径与数学、语文一致（见 [docs/math.md](math.md)、[docs/chinese.md](chinese.md)）。

本学科的特殊之处：**《义务教育俄语课程标准（2022 年版）》只有扫描版 PDF**（111 页整页图，`pdftotext` 只出 111 字节），课标回表所依据的原文先由本仓库 OCR 重建，再做逐字校验。

## 3. 课标回表

- 依据：`~/Desktop/中小学教材/2025修订课程标准TXT /义务教育/《义务教育俄语课程标准》(2022年版) 扫描件OCR.txt`（5283 行 / 75,625 字符）。
- 该 TXT 由 `scripts/ocr_russian_standard.py` 从扫描 PDF **逐页重建**：PyMuPDF 抽整页图 → 2 倍灰度放大 → `tesseract -l chi_sim --psm 3`；第 23 页「简单句」一行整页识别会把「句」读成「铅/名/铝」，改为 6 倍行级重识别并人工逐字核对定本（`LINE_REOCR` / `LINE_OVERRIDE`）。重做单页：`python3 scripts/ocr_russian_standard.py --pages 23`。
- **回表结果：111 条 `quote` 全部命中（111/111）**。判定用「去空白 + 去标点」归一后子串匹配（扫描件 OCR 会丢/改标点，例如漏掉一个分号）；只去空白的严格匹配为 **110/111**，唯一差额是 `rus_p005` 那条引文所在句子——原文用两个分号、OCR 漏掉一个，引文本身已按原文分号改正。
- 本轮改掉的 7 条**非原文引文**（原稿为改写/拼接，不是逐字原文）：
  - `语音知识内容要求1. 掌握 33 个字母读音` → `1. 掌握 33 个字母读音。`
  - `1. 能正确书写 33 个大小写字母` → `能正确书写 33 个大小写字母`
  - `2. 初步掌握俄语书写规范。` → `初步掌握俄语书写规范`
  - `1. 能正确认读 33 个字母。` → `能正确认读 33 个字母`
  - `7. 前置词， 掌握前置词的意义和用法` / `前置词， 掌握前置词的意义和用法` → `掌握前置词的意义和用法`
  - `陈述句、括问句和祈使句的意义和用法` → `陈述句、疑问句和祈使句的意义和用法`（原稿把「疑问句」误作「括问句」）
  - `感知词的音节和重音，了解单音节、双音节和多音节，读准重音，了解重音移动` → 两个分号版（原文用「；」）
- `sourceLine` 全部重算为上述 TXT 中的行号；同一引文在不同知识点中指向同一行号。
- 条目 id 形如 `rus-2022:4.YY.03`，为**本仓库自编**编号，不是教育部原文条号；同一编号下可能覆盖课标相邻条目。
- `confidence` 分布：`exact` 39 · `partial` 64 · `inferred` 8。

## 5. 本轮收口改了什么

`python3 scripts/fix_russian.py --write`（幂等，再跑一遍为 0 处变更）：

1. 难度别名归一：`easy→basic`（20 条）、`medium→standard`（36 条）。
2. 唯一根节点 `rus_p001` 补 `root_reason`（七上第一单元 Урок 1 为零起点起点）。
3. 补齐 10 条「`dependencies` 有、`prerequisites` 缺」的镜像边。
4. 题干 `rus_q011` 由 11 字补到 13 字。
5. 40 个知识点原 `diagnostic_question` 答案为空，按知识点语义逐条补问题＋短答（答案给内容词，不再给裸字母）。
6. 7 条非原文引文改为原文片段 + 111 条 `sourceLine` 重算。
7. 选择题答案位置按 A/B/C/D 轮转拉平（选项文本不动，只换序并同步 `answer`）。

## 6. 已知缺口（不编造，如实登记）

- **九年级下册未建知识点**：教材有该书（人教版九年级下册），本库目前只建到九年级上册；96 个知识点覆盖 5 册。
- **`domain` 未覆盖「语篇 / 语用」**：课标内容要求含语篇与语用，本库知识点只落在语音、词汇、语法三块（语篇/语用类目标未建）。
- **diagnostic_question 采用字母作答**：46 个知识点的 `diagnostic_question.answer` 是选项字母（与数学 469 条、语文 205 条同口径，全库一致），题干本身不自带选项文本；这不是俄语独有缺陷。
- **无 `numeric` 题型**：语言学科不设数值题。

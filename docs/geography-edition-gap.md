## 2. 迁移前的 A 方案缺口（历史记录，已由迁册消除）

1. **一手一册的章号会与新版教材对不上**：学生按新版课本翻「第三章 陆地和海洋」，卷名却是「第二章 陆地和海洋」。
   卷面 `scope` 里带册名＋旧章号，教师可按内容对上；**印成纸质件时必须注明「按 2012 版章序」**。
2. **新版新增「八上 第五章 建设美丽中国」无对应点**：本轮 77 卷里没有这一章的单元卷（41 章口径不含它）。
   补法：先按教材抽该章课时 → 建点 → 配 5–8 题/点 → 再补单元卷；**不要为了凑章节把旧点硬挂过去**。
3. **旧「第一章 地球和地图」在新版被拆成两章**：本轮的「第一章 地球和地图 测试卷」在新版口径下跨两章，
   迁移时按内容拆成「第一章 地球」＋「第二章 地图」两卷。
4. **改名三处**（居民与聚落→居民与文化、中国的疆域与人口→从世界看中国、中国在世界中→奋进中的中国）：
   卷名/学层标题沿用旧名，迁移时**连同 `chapter`、卷名、学层标题、站点索引一起改**（`examId` 不动，防外链失效）。

## 3. 迁移（改成 B 方案）时的固定动作

1. 先改 `data/geography/topics.json` 的 `chapter`（只改章名字段，点与题不动），按本台账第 1 节逐章重写；
2. 同步 `data/geography/exams/**` 的 `paper` ＋ 文件名 ＋ `scope`；`examId` 不动；
3. 同步学层 `data/geography/learn/*.json` 的 `title`（如仍用章名）；
4. 重跑 `build_exam_index.py`、`build_learn_site.py`（含 `learn/index.json`）、`build_standards_index.py`；
5. 跑 `tests/` 与 `scripts/check_geography_exam.py --all`、`scripts/check_geo_learn.py --dir data/geography/learn`；
6. 新版新增章建点后再补卷，别在迁移批里混着建点。

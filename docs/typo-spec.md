# 学科公式与符号书写规范（V1.0）

> 适用范围：本仓所有学科内容（数学、物理、化学、生物，及后续学科）的**文本层写法**与**渲染层转换**。
> 一句话原则：**数据里写人能读的纯文本，排版交给渲染层**。任何"为了好看"而把公式改成图片、或者把上下标塞成组合字符的做法都不采用。

## 0 为什么要有这份规范

同一段内容要出现在四个地方：Word 交付件、网页（讲解页/诊断页）、公众号、以后可能的 PDF。
如果每一处各自排版，就会出现"Word 里是根号、网页里是 `√3` 斜杠分数、公众号里是图片"这种不一致。
本规范把**写什么**（文本层）和**怎么排**（渲染层）分开，四处共用同一份源文本。

## 1 文本层：各学科怎么写

### 1.1 通用

| 项 | 写法 | 禁止 |
|---|---|---|
| 上下标 | `H2O`、`H₂O`、`x^2`、`10^-3`、`m/s^2` 均可 | 组合字符堆叠（`√3̅`）、把上下标画成图片 |
| 乘法 | `×`（数字/单位之间）、`·`（点乘、单位相乘） | 用星号 `*` 代替数学乘号 |
| 减号 | `−`（U+2212）或 ASCII `-` 均可 | 用全角连字符 `－` 混排于公式中 |
| 比与除 | 分数用 `a/b` 或 `a b` 上下排（渲染层转分式） | `a÷b` 之外再混 `/`（同一篇内统一） |
| 空格 | 数值与单位之间留 1 个半角空格：`3 m/s`；`° ′ ″ %` 前不留空格 | `3m/s`（连写） |

### 1.2 数学

- 变量、点、线段、向量：`A`、`点 A`、`线段 AB`、`向量 OA`（渲染层给字母加右箭头）
- 根式：`√3`、`√(x+1)`、`2√6`（渲染层加横线覆盖被开方数）
- 分数：`3/8`、`π/2`、`(a+b)/2`（渲染层转上下叠排）
- 不转的情形（写清楚即可）：`√3/2`（√ 覆盖范围有歧义）、纯字母比 `a/b`

### 1.3 物理

- **量符号斜体**：`v`、`F`、`m`、`ρ`（渲染层把单个拉丁字母排成斜体）
- **单位符号正体**：`m`、`s`、`kg`、`N`、`Pa`、`Ω`、`°C`（渲染层保证不做斜体）
- 单位幂：`m/s²` 或 `m/s^2`；复合单位用中点：`N·m`、`kW·h`
- 词头与单位连写：`km`、`mA`、`μF`（词头不加空格）
- 常数与算符：`g`（重力加速度，斜体）但 `g`（克，正体）——靠上下文区分，正文要写清"质量为 200 g"

### 1.4 化学

- 化学式：`H2O`、`CaCO3`、`Fe3O4`（渲染层把数字转下标）；也可直接写 `H₂O`
- 电荷：`SO4^2-`、`Fe^3+`（渲染层转上标）；离子式同样
- 反应箭头：`->` 或 `→`；可逆 `⇌`；气体 `↑`；沉淀 `↓`
- **条件写在箭头上方**：`->[△]`、`->[催化剂]`、`->[点燃]`；可逆同理 `<=>[△]`
- 状态标注：`(aq)`、`(s)`、`(g)`、`(l)` 写在化学式后，正体不加下标
- 配平系数与化学式之间不加空格：`2H2O2`；系数与系数之间用空格：`2H2O2 + O2`

### 1.5 生物

- **基因符号斜体**：`TP53`、`BRCA1`、`p53`（人类基因全大写；鼠/其他物种首字母大写，如 `Trp53`）
- **蛋白名正体**：`p53 蛋白`、`BRCA1 蛋白`
- **物种学名斜体**：`Homo sapiens`、`E. coli`（属名首字母大写，种加词小写）
- 核酸/蛋白缩写正体：`DNA`、`RNA`、`ATP`、`mRNA`（不斜体）
- 基因型与表现型：基因型斜体（`Aa`、`Bb`），表现型正体（`显性`）

## 2 渲染层：三种通道，一套规则

| 通道 | 数学 | 化学 | 物理 | 生物 |
|---|---|---|---|---|
| Word/OMML | `m:rad` / `m:f` / `m:acc(⃗)` | `m:sSub` 下标、`m:sSup` 电荷、`m:limUpp` 条件 | 斜体 run（量符号）、正体 run（单位） | 斜体 run |
| 网页 | `.rad` / `.frac` / `.vec`（CSS 横线、叠排、箭头） | `<sub>` / `<sup>` / `.rxn`（条件用 ::before 置顶） | `<i class="qty">` / `<span class="unit">` | `<i class="gene">` |
| 公众号 | 同上（网页通道），但公式不与文字同一段混排 | 同上 | 同上 | 同上 |

实现文件：`scripts/math_typo.py`（数学三类）＋ `scripts/subject_typo.py`（按学科调度）。
**渲染函数只接受"学科"参数，不接受调用方临时拼 HTML**，否则规范形同虚设。

## 3 可机检判据（每条都能写成断言）

| # | 判据 | 反例 |
|---|---|---|
| 1 | 渲染后不得出现裸 `√`（必须已是 `.rad` 或 `m:rad`） | 页面里搜到 `√` 文本节点 |
| 2 | 渲染后不得出现 `数字/数字` 斜杠式分数 | `3/8` 原样显示 |
| 3 | 化学式的数字必须落在下标位（`<sub>` 或 `m:sSub`） | `H2O` 里 2 与 O 同基线 |
| 4 | 反应条件必须出现在箭头上方，不得写成"箭头后括号" | `→ (△)` |
| 5 | 单位符号不得斜体；量符号不得正体（同一处只能一个） | `m/s` 斜体 |
| 6 | 基因符号斜体、蛋白名正体 | `TP53 蛋白` 里 `TP53` 正体 |
| 7 | 数值与单位之间有且仅有 1 个空格 | `3m/s`、`3  m/s` |
| 8 | 一个段落内不得混用 `÷` 与 `/` 表示除法 | 上文 `a÷b`、下文 `a/b` |

## 4 边界与已知取舍

1. **不追求 LaTeX 级排版**：不做多行公式对齐、矩阵、积分上下限的精细排版——教材以文字讲解为主，过度排版反而让 Word 文件难以二次编辑。
2. **斜体只对"可判定"的位置生效**：单个拉丁字母紧邻 `= ≤ ≥ ≈ × /` 或出现在"设/求/记"之后才排斜体；`DNA`、`ATP`、`GPS` 这类缩写在白名单里永不斜体。
3. **单位白名单制**：只认 SI 词头 + SI 单位 + 常用导出单位；不在白名单里的（如 `pH`、`rpm`）按普通文本处理，不做正斜体转换。
4. **化学式靠元素白名单**：`H2O` 会转，`ATP`、`B2B` 不会（首字母不在元素表或组合非法）。宁可少转，不可错转。
5. **条件在箭头上方**是唯一比纯文本"多出来的排版"；如果某处箭头条件写不出（如条件很长），允许降级为"箭头 + 紧随括号"，但要在该处保留原文并在审计里登记。

## 5 与既有实现的关系

- `docs/math-learn-spec.md` 管的是**学层文章的结构**（七段、字数）；本规范管的是**符号怎么排**，两者正交。
- `scripts/math_typo.py` 里的 `FRAC_RE`、`RAD_RE`、`VEC_RE` 三套正则被 `subject_typo.py` 复用，不重复实现。
- Word 交付件的 `build_math_learn_docx.py` / `build_math_exam_docx.py` 已接 `math_typo`；接入 `subject_typo` 时只换 import 与传 `subject=`，其余逻辑不动。

# 试卷讲解（单元卷 / 期中 / 期末）内容层规范 V1.0

> 与「诊断讲解」（`docs/math-learn-spec.md` 的学层精讲）同级的学生端内容：
> 学层是**按课时**讲「这一课怎么学」，试卷讲解是**按整卷**讲「这份卷怎么打、每道题怎么想」。
> 两者共用同一套公式排版通道（`scripts/subject_typo.py`），不许另起写法。

## 1 输入

| 材料 | 路径 |
|---|---|
| 卷面 JSON | `data/math/exams/<册>/<卷名>.json`（含 `examId/kind/scope/sections[].items[]{no,stem,answer,analysis,topicIds,score}）` |
| 课时点 | `data/math/topics.json`（chapter 形如 `<册> <单元> <单元名> · <课时名>`） |
| 学层精讲 | `data/math/learn/<册>.json`（讲到某个点时引用其"方法锚"，不要重复整篇） |

## 2 输出

`data/math/exam_lectures/<册>/<卷名>.json`：

```json
{"examId": "mat_exam_g1a_u3", "book": "一年级上册", "paper": "第三单元测试卷",
 "kind": "unit", "markdown": "# …", "words": 4321}
```

`markdown` 用纯 Markdown，公式一律写**纯文本**（`√3`、`3/8`、`2x+1`、`H2O`、`3 m/s`），
由渲染层转规范排版——**禁止**在数据里写 OMML/HTML/组合字符。

## 3 正文结构（五段，顺序固定）

1. **一、这份卷在考什么**（300–500 字）
   满分/时长/题量、难度分布（basic/standard/hard 各几题）、覆盖哪几个单元与课时点；
   一句话点明"这份卷的一个核心难点"。
2. **二、考点地图**（表格化的清单，用列表）
   按大题列：`大题名 → 题号区间 → 考的是哪个课时点 → 分值`；
   最后一行给出"分值最重的三个考点"。
3. **三、逐题精讲**（主体，占 60% 以上字数）
   每题固定四行，题号必须与本卷 `no` 一致：
   - `**第 N 题（X 分）**`：一句话说这题在考什么
   - **思路**：从题干哪个条件入手、用到哪条结论（写"为什么想到"）
   - **关键一步**：最容易卡住或算错的那一步，写出算式与结果
   - **易错**：学生真实会犯的错（错因，不是"粗心"），并给出正确写法
   `choice` 题要说明干扰项为什么错；`solve` 题给分步得分点（与卷内 `scoreRule` 一致）。
   允许合并同类简单题：`第 5、6 题` 合并成一条，但**每道题的题号都必须出现一次**。
4. **四、整卷复盘**（300–500 字）
   本卷三个高频错因（按卷面实际题归纳）、时间分配建议（分钟数按 `duration` 折算）、
   建议的作答顺序（先拿哪些分）。
5. **五、自查清单**（6–8 条 `- [ ]`）
   每条可判定（如"能否不列竖式说出 2x+1 在 x=3 时的值"），不要"认真检查"这类空话。

## 4 铁律

1. **与卷面一致**：题号、题分、答案、`scoreRule` 一个字都不能改；讲解只解释，不改题。
2. **不重复 `analysis`**：卷内 `analysis` 已给"为什么对"，讲解要补"为什么想到 + 会怎么错"。
3. **公式写法**：按 `docs/typo-spec.md`。**根号里是分数或除式时必须加括号**：`√(9/2)`、`√(a/b)`、`√(54÷6)`；
   只开一个数就不用括号（`√32`、`2√6`）。写成 `√9/2` 会被读成「√9 再除以 2」，属于硬伤。数值与单位空一格（`3 m/s`）、分数写 `3/8`、根式写 `√3`、
   化学式写 `H2O`、基因名直接写（由渲染层决定正斜体）。
4. **字数**：小学卷 3,500–6,500 汉字；初中卷 4,000–7,000；高中卷 4,500–8,000。
5. **不超纲**：只讲本卷涉及的知识点；需要前置知识时引用学层对应课时的"方法锚"，不展开新内容。
6. 一题一行留白：题与题之间空行，便于 docx 渲染时按段分行。

## 5 自检（必须 exit 0）

```bash
python3 scripts/check_exam_lecture.py data/math/exam_lectures/<册>/<卷名>.json
```

检查：字数带、五段齐全、**逐题覆盖**（卷内每个 `no` 都在讲解里出现）、题分一致、
易错行数与题数匹配、公式反例（`^`、`数字/数字` 斜杠分数、单位缺空格）为 0、无 LaTeX/HTML。

## 6 渲染

```bash
python3 scripts/build_exam_lecture_docx.py                # 全部
python3 scripts/build_exam_lecture_docx.py 一年级上册      # 单册
```

输出：`~/Desktop/学科图谱相关资料/试卷讲解/<学科>/<版本>/<册>/<卷名>_讲解.docx`
公式走 `subject_typo.docx_segments(text, subject)`；学科由册名推断（数学/物理/化学/生物）。

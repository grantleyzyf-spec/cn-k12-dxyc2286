## 9. 题库答案位均衡（确定性换位，2026-11-01）

**问题**：历史建点脚本一律把正确项写在第一个选项，导致全库 1459 道选择题里 **90.1% 的答案落在 A**（A 1315 / B 103 / C 26 / D 15），学生只要「见 A 就选」即可拿到九成正确率，诊断与测评的区分度被架空。

**修法**（`scripts/fix_cn_answer_position.py`，确定性、可复算、幂等）：

1. 全库选择题按 `md5(id)` 排序，按序号 `i % 4` 分配目标位置 ⇒ A/B/C/D 各占恰 1/4；
2. 目标位置放**原正确项**（按选项文本识别，不依赖当前顺序），其余三项按 `md5(选项文本)` 升序填充；
3. 重新标 A/B/C/D，`answer` 改为正确项的新标号。

只动 `options` 顺序与 `answer` 标号：**题干、选项文本、解析、难度、题型、topicId 一律未变**（脚本内断言选项文本集合一致、每题正确项文本未变）。因正确项按文本识别、其余按文本哈希排序、目标位置只依赖 id，重跑结果字节相同（实测第二次「实际改动 0 / 1459」）。

**结果**：A 365（25.0%）· B 365（25.0%）· C 365（25.0%）· D 364（24.9%）；实际换位 1390 / 1459 题（69 题原位置恰好命中）。
门禁复跑：`validate.py chinese` 0 error、`test_chinese.py` 32/32、`check_cn_bank.py --book 八年级上册 --count` 通过、schema（topic+question）通过。

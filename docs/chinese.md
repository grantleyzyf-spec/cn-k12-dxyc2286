# 语文（`chinese`）

语文按「数据 → 课标回表 → 题库 → 自检 → 文档 → 页面口径 → CI」七件套收口，口径与数学一致（见 [docs/math.md](math.md)）。

## 3. 课标对齐

- 依据：《义务教育语文课程标准（2022 年版 2025 年修订）》＋《普通高中语文课程标准（2017 年版 2025 年日常修订）》本地 TXT 快照。
- **234 条 `quote` 全部逐字回表**：课标 TXT 去空白后子串匹配，命中 **234 / 234**（`scripts/test_chinese.py` 会重跑；CI 无 TXT 时自动跳过）。
- 条目 id 形如 `cyw-2022:1.SX.02`，为**本仓库自编**，不是教育部原编号。
- `confidence` 分布：`exact` 26 · `partial` 150 · `inferred` 58。

## 5. 本轮归一明细（2026-10 收口）

1. **领域纠偏 205 条**：原数据除 44 条外全部误标为「拼音」（含习作、议论文阅读、古诗文、修辞），已按关键词规则重挂四领域。
2. **难度三档**：205 条原全部 `easy`（别名），按知识点类型定档 → `basic 144 / standard 47 / hard 14`。
3. **根节点 `root_reason` 4 条**：四个无前置节点补齐理由。
4. **先修边**：删除伪边 `chi_p006 → chi_p007`（韵母与声母并列，非先后），补 3 条 `prerequisites` 有而 `dependencies.json` 缺的镜像边，去掉 4 条重复边。
5. **题干 <12 字 13 条**补上下文（原仅 ≥8 字过 `validate.py`，不达题库口径）。

## 6. 已知缺口（不编造，如实登记）

- 题面全为选择题（205/205），暂无填空/简答题；小学低年级可用，高中鉴赏与写作类题目偏浅。
- `梳理与探究` 领域仅 1 个知识点，「综合性学习」在教材中的份量明显高于图谱覆盖。
- `confidence` 以 `partial` 为主（150/234），`exact` 仅 26 条：课标条目与知识点的粒度并不一一对应，属结构性缺口。
- 高中 12 册（选择性必修下册）13 条，与上册、中册相比偏少。

## 7. 自检与 CI

```bash
python3 scripts/validate.py chinese          # Total Errors: 0
python3 scripts/test_chinese.py              # 32/32 项通过 → CHINESE DATA PASSED
python3 scripts/build_stats.py --write       # 统计现算
python3 scripts/build_standards_index.py     # 改数据后必跑，否则 CI 新鲜度闸门红
```

`scripts/test_chinese.py` 覆盖 32 项不变量：规模 / 唯一 / 册次 / 课标可解析 / quote 回表 / confidence / 边无环无重 / 双向镜像 / 根节点 reason / 每点有题 / 4 选项 / 题干 / 解析 / 字段 / 掌握标准 / 领域合规 / 三档难度。

## 8. 页面用法

- 学科页 `?subject=chinese`，册次用 `?book=必修上册` 过滤；`#<id>` 可直接定位知识点。
- 册名从 `chapter` 派生，不要用 `grade` 直接当册名（见 `references/page-book-label.md`）。

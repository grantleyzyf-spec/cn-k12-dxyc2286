# 西班牙语（`spanish`）

西班牙语按「体检 → 数据重建/归一 → 课标回表 → 题库 → 自检 → 文档 → 页面口径 → CI」收口，口径与数学一致（见 [docs/math.md](math.md)）。

本轮的特别之处：**旧数据只有 29 个知识点**（七~九年级 + 必修 + 选必一共 29 点，等于每册 2–4 点），无法支撑「已完成」。因此不是洗旧数据，而是**以本机 12 册外研社版教材 PDF 原文为准整科重建**，再把旧数据里的东西全部作废替换。

## 3. 课标对齐

- 唯一权威源：《普通高中西班牙语课程标准（2017年版2020年修订）》PDF（本机 `中小学教材/2025修订课程标准/普通高中课程方案及20科课程标准（2017年版2020年修订)/21.…pdf`）。义务教育阶段我国没有独立的西班牙语课标文本，本库按课标自身的学段设计——**必修Ⅰ/Ⅱ/Ⅲ 对应义务教育七/八/九年级**（课标「教学提示」明确必修Ⅲ 需「保证学生顺利通过义务教育阶段的学业评价测试」）——把义教 5 册对齐到 1/2/3 级，高中必修Ⅳ 对齐 4 级，选必对齐 5 级，选修（6 级）暂无教材不建点。
- **条目 id 自描述**：`spa-2017:G.<CAT>.<级>.<条>`，`CAT` = `TING`听 / `SHUO`说 / `DU`读 / `XIE`写 / `CH`词汇知识 / `YF`语法知识 / `WH`文化知识 / `SW`思维 / `CL`策略。例：`spa-2017:G.YF.2.1` = 必修Ⅱ（2 级）语法知识第 1 条「掌握命令式的变位规则和用法」。**不是教育部原编号**，只在本仓库内部可追溯（与 README「课标条目 id」口径一致）。
- **246 条目录 100% 回表**：`python3 scripts/verify_spanish_catalog_source.py` 把目录里每条 `quote` 与课标 PDF 抽出的原文去空白后子串匹配，命中 246/246；课标 PDF 不在本机（CI）时自动跳过。
- **知识点侧 194 条引文逐字一致**：`scripts/test_spanish.py` 校验每条 `standards[].quote` 与目录同 id 条目**逐字相等**（不是片段匹配），因此 CI 没有课标 PDF 也能守住引文真实。
- `confidence`：`exact` 179 · `partial` 15（跨级复现条目按 `partial` 记，如 1 级内容在 2 级教材中复现）。
- 课标按 level 分布：1 级 48 条 · 2 级 32 · 3 级 14 · 4 级 41 · 5 级 59。

## 5. 本轮做法（可复算）

1. **教材原文抽取**：12 册 PDF 用 PyMuPDF 逐页抽文字到 `/tmp/spa_txt/<vol>.txt`（含 `===== PAGE n =====` 标记），单元标题一律从原文抄，不自造。
2. **课标条目目录**：从课标 PDF 的「四、课程内容 → 【学业要求】」按 听/说/读/写 + 词汇/语法/文化知识 + 思维/策略 分块解析出 246 条，`quote` 取每条的逐字片段（跨页断开处自动截到可回表的前缀）。
3. **分册内容工位**：12 册并行产出 `{volume, book, topics[], questions[]}`，每册受 `spa_check_fragment.py` 硬闸约束（册名↔grade↔课标 level 三重对表、quote 逐字、4 选项、难度三档、册内先修闭合）。
4. **合并**：`python3 scripts/merge_spanish_volumes.py --fragments /tmp/spa_build --write`
   - 按册序**统一重编 id**（分册工位各自从 001 编起，必须重编，否则跨册撞号）：义教 `spa_p001…`、高中 `spa_h001…`；
   - 跨册先修按 `prereq_names` 解析（归一化名称 → 精确 → 唯一包含 → 相似度 ≥0.72 唯一最高）；
   - **册间断链兜底**：某册没有任何跨册入边时，用上一册「末个语法/交际知识点」接本册首个根知识点，保证 DAG 连通；
   - 逐条试加边做**环检测**，会成环的边丢弃并报告（本轮丢 1 条）。
5. **归一与索引**：`rebuild_aggregates_only.py` → `build_standards_index.py` → `build_stats.py --write`。
6. **旧数据处置**：原 29 点（`spa_p001…spa_h005` 旧含义）整批替换为新数据，**不做 id 别名**——旧 id 与新知识点语义不对应，挂别名会把旧链接指到错的知识点上；旧页面深链失效属预期（`data/id-aliases.json` 保持空）。

## 6. 已知缺口（不编造，逐条登记）

1. **九年级必修Ⅲ下册教材缺**：本机只有必修Ⅲ上册，九下无 PDF，故该册不建点（册次表里没有九年级下册）。补齐教材后可增 10–12 点。
2. **选修（6 级）无教材**：课标 6 级 47 条目录条目已建好（`level=6`），但无教材 PDF，不建点。
3. **听力类课标条目不建点**：`TING` 36 条目录条目 0 引用——听力属技能训练，不作为图谱知识点；说/读/写按教材读写任务择要挂点（`SHUO` 10 · `DU` 11 · `XIE` 8）。`CL` 学习策略 24 条同样未挂。
4. **跨册先修按名称解析，117 条未命中**：分册工位互相看不到对方的知识点命名，声明的跨册先修名有 117 条在本库找不到同名点（例如「规则动词现在时(-ar)变位」在七上已被并成「规则动词-ar的陈述式现在时变位」之前就被引用）。未命中的不连边，靠 §5 的骨架兜底边保证连通；后续可用 `prereq_names` 归一表人工收敛。
5. **颗粒度**：每册 10–14 点，以「一个语法规则/一个交际功能/一处文化主题」为一点；词汇只建主题词汇场与构词法，未做逐个词条。

## 7. 自检与命令

```bash
python3 scripts/test_spanish.py                    # 42 项不变量（含册名↔grade↔课标 level、引文与目录逐字一致、先修无环）
python3 scripts/verify_spanish_catalog_source.py   # 246 条目录条目对课标 PDF 逐字回表（无 PDF 时跳过）
python3 scripts/validate.py spanish                # 结构/引用
python3 scripts/merge_spanish_volumes.py --fragments /tmp/spa_build --write   # 需要重建时
```

CI：`.github/workflows/validate.yml` 已加「Subject invariants · spanish」与「Spanish standards catalog …」两步，与数学/生物/历史自检同列。

## 8. 页面用法

- 学科选「西班牙语」→ 学段选「高中」→ 册次下拉出现 `必修四第一册 / 必修四第二册 / 必修四第三册 / 选必一 … 选必四`（按 grade 排序，不受册名登记表影响）；
- 义教侧按年级 + 上下册筛，册名由 `chapter` 派生；
- 可分享链接：`?subject=spanish&book=必修四第二册#spa_h023`。

# 峰谷调度（重负载只在波谷跑）

> 用户口径（2026-11-02 明确，覆盖此前「工作日峰 / 周末全谷」的旧写法）：

- **波峰**：`09:00–12:00`、`14:00–18:00`
- **波谷**：`12:00–14:00`、`18:00–次日 09:00`

## 1 什么算重负载（只在波谷开跑）

- 多工位并发写内容：题库分片、学层精讲、试卷、试卷讲解（`delegate_task` 批量派单）
- 批量渲染 / 批量转 docx / 批量 PDF→图片
- 全库扫描与全量比对（`validate --all`、相似度全量审计、跨册查重）
- OCR、教材整册抽取

## 2 波峰只做轻量活

合并分片、跑单点门禁、重建索引、生成 docx、写文档、汇报、代码修补、`git` 提交与推送。

## 3 在飞的工位不中途杀

已经派出去的工位跨到波峰时**不停止**（杀了等于把已投入的时间白烧）；但**波峰期间不再新开批**，
下一批等 12:00 或 18:00。

## 4 闸门脚本

```bash
python3 scripts/peak_valley.py                 # 当前段 + 下一次切换
python3 scripts/peak_valley.py --is-valley     # 波谷 exit 0 / 波峰 exit 3
python3 scripts/peak_valley.py --next-valley   # 下一个波谷起点
python3 scripts/peak_valley.py --at 10:30      # 查指定时刻
```

派单前的固定写法（波峰直接拦住）：

```bash
python3 scripts/peak_valley.py --is-valley && echo "开批" || echo "波峰：不开新批"
```

`14:00`波峰 / `17:59`波峰 / `18:00`波谷 / `23:30`波谷 / `05:00`波谷。

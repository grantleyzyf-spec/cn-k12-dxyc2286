## 三、编号与字段口径

- 知识点 id：苏教版 `msj_p###`（小学/单元）、`msj_p1###`（课时）、`msj_h###`／`msj_h1###`（高中）；苏科版 `msk_*` 同规则。
- `chapter`：`<册名> 第N单元 <单元名>`（高中/苏科为「第N章」），课时点追加 ` · <节名>`。
- 册名一律带版本前缀（`苏教版一年级上册` / `苏科版七年级上册` / `苏教版必修第一册`），与人教版（裸册名）不冲突。
- 单元点 5 题、课时点 8 题；课时点带 `page`（教材印刷页，目录未给者留空）与 `misconceptions`（≥2 条）。
- `domain` 按学段两套口径：义务教育用四领域（数与代数／图形与几何／统计与概率／综合与实践），高中用三主题（函数／几何与代数／统计与概率）。判定按单元名关键词，顺序为「统计 → 图形 → 综合与实践 → 数与代数」，避免「数据的收集、整理与描述」被「整理」误判成综合与实践（已实测修正）。
- `subject` 仍为 `math`：站点按「出版社」维度区分，不新增假学科。

## 四、数据来源与可靠性

1. **教材**：全部 PDF 为扫描件（文字层仅页码），逐页 200dpi 渲染 + `tesseract chi_sim` OCR；目录页另用 vision 逐字核读并与文字层互校，页码偏移逐册实测（小学多为 PDF−7/−8，高中 PDF−7/−6，苏科 PDF−7）。
2. **小学课时名**：苏教版新教材目录只到单元级，课时名取自 `大单元整体教学设计` docx 的「教-学-评一致性课时设计」段（`_scripts/extract_keshi_docx.py`，18 册/133 单元/1027 课时）；章末板块（小结与思考、复习题、数学探究、综合与实践、数学建模）**不进课时点**。
3. **题材包**：`textpack.py` 把逐页 OCR 拼成带页码标记的单文件；汉字占比低于 25% 自动改走 PDF 文字层（三上已触发），有二次 OCR 时优先用它（必修第一册）。
4. **课标 quote**：`map_standards.py` 逐点匹配课标原句并自检「去空白后必须是原文子串」——苏教版 487/501 命中、苏科版 140/141 命中，其余标 `inferred`。

## 五、已知缺口

1. **教材缺册**（按用户令「等新教材」）：苏教版四下、五下、六下；苏科版九下。
2. **课时名来源**：小学课时名来自本单位教学设计 docx，非教材印刷标题；教材只印「例1/例2」的单元（如二上第四、六单元），课时按单元名记 1 节并在脚本 notes 标注。
3. **课时名与教材措辞不一致的个案**：`s1b` 第六单元原按 docx 写作「求被减数／求减数」，经该册题材包核验（「被减数」0 次、「相差」6 次）已改为「求相差数的实际问题」「求比一个数多几（少几）的数」，改名处集中登记在 `build_skeleton.py::LESSON_NAME_FIX`，可复算。另有 `s2b` 一上「线段的认识与画法」一名在该册 OCR 文本里查不到「线段」字样（OCR 缺失所致，教材实有此内容），暂按通用口径保留。
4. **页码部分留空**：小学课时点 `page` 多由 docx 推导，无页码者留空，需按单元起页在题材包里定位。
4. **课标未匹配 15 条**：多为「综合与实践」类点（苏教 14、苏科 1），课标无对应条目句，`standards` 为空属正常。
5. **站点未挂载**：`learn/`（学层精讲）、`exams/`（试卷）尚未生产，故这两版暂不进入站点「讲解／整卷」入口；知识点图谱数据本身已可按 `data/<subject>/*.json` 读取。

# 数学「学层」学生版精讲：内容层工位说明书（V1.0）

> 目标：给每个课时点写一篇**学生自己能读懂**的精讲（1000–2000 汉字），
> 方法沿用公众号「学霸轻松养成」那套**费曼拆解**：先摆课本原文，再翻成大白话，例题分步，点明明错。
> 产出放在 `data/math/learn/<册>.json`，site 直接渲染，也可一键出 docx 给学生打印。

## 1 为什么要有这一层

现在的数据链已经有「练（题库 5 题）→ 测（单元/期中/期末卷）→ 诊断（四档掌握度＋前置缺口＋错因）」，
但每个课时点只有 71 字（中位）概述——**学生点进去没东西可学**。学层补的就是这块。

## 2 输入

| 材料 | 路径 |
|---|---|
| 本册课时点（含 topicId、name、chapter、misconceptions） | `data/math/topics.json`（chapter 形如 `<册> <单元> <单元名> · <课时名>`） |
| 本册教材 PDF | 小学 `…/数学/小学/人教版/*.pdf`、初中 `…/数学/初中/人教版/*.pdf`、高中 `…/数学/高中/人教版（A版）/*.pdf` |
| 公式（高中） | `docs/math-hs-formula-ledger.md`（**不得**从 OCR 抄公式） |

印刷页 → PDF 页序偏移**逐册不同**，下面这张表是写手实测值（1 基 PDF 页 = 印刷页 + N）：

| 偏移 | 册 |
|---|---|
| +4 | 一下、二上、二下、选必二 |
| +5 | 一上、三上、三下、四上、五上、六上、选必一、选必三 |
| +6 | 八上、九上 |

## 3 输出

`data/math/learn/<册>.json`：

```json
{
  "book": "七年级上册",
  "lessons": [
    {"topicId": "mat_p1022", "title": "1.1 正数和负数",
     "markdown": "# 1.1 正数和负数\n\n## 一、开场…\n", "words": 1287}
  ]
}
```

`markdown` 用纯 Markdown（不写 HTML），行内公式用 Unicode 符号（≤ ≥ √ ∈ ² ³ π），**不写 LaTeX**。

## 4 正文结构（六段，顺序固定）

1. **一、开场：一个生活场景**（150–250 字）
   用一个学生熟悉的情境起头（温度、账单、体重、水位、球场得失球、海拔…），提出本课要回答的那个问题。
2. **二、课本原文说了什么**（至少 2 处 `> ` 引用）
   逐字引用教材定义/关键句，用 `> ` 块引用，每处 ≥8 字；引用后紧跟一句「这句话的意思是……」。
3. **三、费曼翻译：用大白话说清楚**（300–500 字）
   把定义翻成大白话＋一个生活类比；写清「为什么要这样规定」「不这样规定会出什么问题」。
4. **四、例题精讲（2 道）**（400–700 字）
   取教材例题或同类变式，按「审题 → 第一步 → 第二步 → 答案 → 回头看」分步写；
   每道题至少一处 `❌ 常见错法` 与 `✅ 正确做法` 对照。
5. **五、易错点拨**（≥2 条，优先直接用该课时点的 `misconceptions`）
   每条写「错在哪 → 为什么错 → 怎么防」，一句话能带走。
6. **六、五步学习法：这一课怎么学**（400–600 字，5 条，每条 ≥25 汉字）
   固定五步，顺序不可改，**每步必须结合本课时内容**（不许写成通用励志话）：
   ①**每天锻炼一个小时**——说清这本课怎么用身体感受/运动后做哪类题更有效；
   ②**扎实掌握第一个知识点**——点明本课的第一个知识点是什么，给出把它练熟的具体做法；
   ③**能积微者速成**——给一个每天 3 分钟起的微习惯（具体到题型与题量）；
   ④**运用对标思维突破学习困境**——指定一个可观察的对标动作（看谁、学哪个动作）；
   ⑤**运用杠铃法则缓解学习疲劳**——时间怎么配（如 25 分钟专注＋5 分钟彻底放松）。
7. **七、方法锚 + 自查**（150–300 字）
   一句口诀/方法总结（加粗），再给 **3 道自查题**（用 `- [ ]` 列表），题目要能从本课正文找到答案。

## 5 铁律

1. **字数**：教学正文 1000–2000 汉字，五步学习法 400–600 汉字 ⇒ **全篇 1200–2600**（机检按去符号汉字数算）。
   抬高上限的原因：五步学习法是必备节，若仍卡 2000 就只能砍教学正文，得不偿失。
2. **引文逐字**：`> ` 引用必须能在本册教材正文里逐字命中，不许改写、不许拼接、不许凭印象编。
3. **例题必须算对**，步骤可复现；数值结论自己复算一遍。
4. **只讲本课时**，不提前教后面课时的解法（可提一句"后面会学"但不展开）。
5. **学生视角**：不用"我们要求学生……"这类教师语；不写"考点/得分点"这类考试黑话（可写"考试常这么问"）。
6. 不使用 LaTeX、不写 HTML 标签、不用表格（手机端渲染差）。
7. 易错点拨优先用 `topics.json` 里该点的 `misconceptions` 原文，可改写为给学生看的语气。

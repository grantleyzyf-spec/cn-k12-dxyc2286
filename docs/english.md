## 3. 课标口径（两级，别混报）

- 依据：《义务教育英语课程标准（2022 年版 2025 年日常修订）》＋《普通高中英语课程标准（2017 年版 2025 年日常修订）》的本地 TXT 快照。
- **第一级「已挂课标」**：204 / 204 个知识点 `standards` 非空——204/204，即 100%。
- **第二级「带原文引文」**：204 / 204 个知识点至少有一条 `quote`——204/204；引文条数合计 232 条。
- 引用的课标条目去重后 170 条，全部能在索引里解析到；索引条目共 170 条，覆盖 170/170。

- 条目 id 形如 `eng-2022:…`（义教 101 条）/ `eng-2017:…`（高中 69 条），是**本仓库自编**，不是教育部原编号。

## 4. 难度与题型

### 4.1 判定规则（可复算，写在 `scripts/` 同口径的脚本里）

本轮把原本清一色 `basic` 的 204 道题按下面三条规则重判，规则只看题面（题干 + 选项）里可见的事实：

1. **`basic`（默认档）**：题干不留空、考的是单词/短语的直接识记与辨认，如
   `Which colour is the sky on a sunny day?`（Colours 话题，选项 Red/Green/Blue/Yellow）。
2. **`standard`（辨析 / 语境选择）**：命中任一条即升档——
   - 题干留空，需按语境在同类词中选词（`I write with a ____.`）；
   - 题干是两轮以上的对话，需按上句的助动词与人称作答（`—Do you like pears? —____`）；
   - 四个选项都是完整句子，需按语境判断应答（`—How much is the shirt? —____`）；
   - 否定/排除式题干（`Which is NOT a fruit?`）。
3. **`hard`（多步推理 / 跨句）**：同时满足「题干留空 **且** 选项属同一词形家族（≥3 个选项共享 3 字母前缀，或 ≥3 个是 be 动词/助动词）」**且**「题干带时间·情景线索（yesterday / last night / before / Look! / now / than / one of …）或跨句（两处以上句末标点）或 there be + 并列主语」——
   即必须先读语境、再定形式的**两步判断**，如
   `Look! The children ____ in the park.`（play/plays/are playing/played）、
   `I ____ at home yesterday.`（am/is/was/were）。

### 4.2 实际分布

| 难度 | 题数 | 占比 |
| --- | ---: | ---: |
| `basic` | 130 | 63.7% |
| `standard` | 65 | 31.9% |
| `hard` | 9 | 4.4% |

目标分布是 60 / 35 / 5，实际落在 63.7 / 31.9 / 4.4：

其余是无空格的直接辨认题——按规则它们只能是 `basic`，没有为了凑比例去改判。

## 5. 已知缺口（如实记录，不编造）

1. **`domain` 口径偏窄**：151 个知识点的 `domain` 都写作「语音」，但其中大量是问候语、颜色、动物等**话题词汇**；`语法` 45、`词汇` 8。这是原始录入的粒度问题，本轮只做难度/解析/根因归一，**没有**重挂 `domain`（重挂会牵动页面筛选与其它学科的对照口径，需整批处理）。
2. **`inferred` 33 条**：教材有该知识点、课标只给上位表述，标注为推断而非直引；`partial` 152 条同理。两者都**不动引文原文**。
3. **难度未经学生作答数据校准**：三条规则是题面口径的可辩护近似，不是实测区分度；`hard` 仅 9 道。
4. **题库全是选择题**：无填空/数值题，因此没有可 `eval` 的 `verify` 字段（`test_english.py` 对非数值题不做该项要求）。
5. **个别题干与原知识点名称错位**：如 `eng_p043_q894`「I ____ at home yesterday.」挂在 `eng_p043 Places in a city` 名下。按「不改题干、不改 `topicId`」的红线保留；解析只依据题干与选项本身的事实写，不引用知识点名称，避免把错位名称带进解析。
6. **`grade` 与册次非一一对应**：grade 12 混有选必二/三/四与「高考复习」共 12 个知识点；页面详情卡与左侧列表按 `chapter` 派生的册名显示（含「高考复习」），
   但顶部册次下拉是按 `grade` 分组生成的，选「选必一」不会自动带出 grade 12 里的选必二/三/四——属已知显示局限，**不改页面 JS**。
7. **解析不是课标引文**：第 4 节的解析是按「正确项 + 错项纠错」口径生成的逐题说明，不可当课标原文引用；课标原文只取 `standards[].quote`。

## 6. 自检与校验

```bash
cd cn-k12-dxyc2286
python3 scripts/test_english.py            # 25 项不变量（规模/唯一/册次/课标/回表/边/根节点/题）
python3 scripts/validate.py english        # 单学科结构校验
python3 scripts/validate.py --all          # 17 学科全量（CI 同款）
python3 scripts/build_standards_index.py   # 改数据后必跑：重建课标索引
python3 scripts/build_stats.py --write     # 刷新 data/stats.json（首页数字）
```

`test_english.py` 的 25 项：知识点 204 条 / 题目 204 道 / 先修边 209 条、id 唯一、`subject` 全为 english、题与点 1:1、
年级覆盖 3–12、核心字段齐全、掌握标准 1–3 条、全部知识点挂课标、课标 id 可解析、每条带 `quote`、
`confidence` 三档、`quote` 逐字回表 100%（无 TXT 时跳过）、先修边无自环且无重复、两端存在、边类型 hard/soft、
`deps ↔ prerequisites` 双向镜像、先修图无环、根节点有 `root_reason`、每个知识点都有题、难度三档齐备、
选择题 4 选项且答案在选项内、题干 ≥8 字、每题解析 ≥20 字。CI 里作为 `Subject invariants · english` 一步跑。

## 7. 页面怎么用

- 首页点「英语」→ `explore/?subject=english`，默认落在关系最密的知识点，可搜索、按册次/领域筛选、点节点换中心。
- 册次下拉：小学段显示「三年级…六年级」（含上/下册），高中段直接显示**册名**——必修一 / 必修二 / 必修三 / 选必一 / 选必二 / 选必三 / 选必四 / 高考复习，不会出现「十年级」。
- 深链可复现：`explore/?subject=english&book=必修一#eng_h001`（`book=` 接册名，`#` 接知识点 id）。
- 诊断：`diagnose/?subject=english`，选目标知识点后沿 hard 先修边回溯出题；结果只存本机 `localStorage`。

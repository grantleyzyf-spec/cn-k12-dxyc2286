## 3. 本轮收口做了什么（2026-10-27）

1. **册次纠错**：九年级第八～十二单元原被标成「上册 / 第一学期」，按人教版编排改为 `九年级下册` / `下`（13 条）。
2. **章名纠错**：必修第一册第二章补全为「海水中的重要元素——钠和氯」，`chem_h004/h005` 由章级名 `金属及其化合物`、`非金属及其化合物` 改为 `钠及其化合物`、`氯及其化合物`；必修第二册第四章的三条（元素周期表/元素周期律/化学键）归回**必修第一册第四章**；选择性必修册名统一为「选择性必修第一/二/三册」，页面 `bookLabel` 才能派生出「选必一/二/三」。
3. **结构缺口补点 10 个**：物质的量（必修一第二章）、铁及其化合物与金属材料（必修一第三章）、硫及其化合物、氮及其化合物、无机非金属材料（必修二第五章）、自然资源的开发利用、化学品的合理使用与环境保护（必修二第八章）、原电池、电解池（选必一第四章）。
4. **题目 id 缺陷修复**：27 条高中题的 `id` 全部写成重复的 `chem_qhem_`（`validate.py` 只查结构不查唯一性，故一直未暴露），按序重编为 `chem_q036…chem_q062`。
5. **难度三档**：原 62 题全为 `easy`，按认知负荷重挂 `basic 35 / standard 28 / hard 14`（`easy/medium` 别名已清零）。
6. **数值题 5 道**：化学方程式计算、溶质质量分数、物质的量、pH、化学平衡常数各 1 道，`verify` 为可 `eval` 的表达式，答案与复算一致由 `test_chemistry.py` 校验。
7. **先修边**：补 10 条新边、补 7 条 `deps ↔ prerequisites` 镜像、2 个根节点补 `root_reason`。

## 6. 已知缺口（如实记录，不编造）

1. **7 个新增节级知识点暂无课标条目**：`chem_h028` 物质的量、`chem_h030` 金属材料、`chem_h033` 无机非金属材料、`chem_h034` 自然资源的开发利用、`chem_h035` 化学品的合理使用与环境保护、`chem_h036` 原电池、`chem_h037` 电解池。原因是 `data/cn-curriculum-standards.json` 的化学条目是「本库实际引用过的条目索引」（63 条，粗粒度主题），这七处对不上现成编号；**留 `standards: []`，不新编编号**。
2. **粒度仍偏教材节级**：九年级部分知识点按「课题」合并（如「金属的化学性质」覆盖置换与活动性顺序），比数学（479 点）粗；跨学科横向比较需注意口径。
3. **难度标签未经学生作答数据校准**，`hard` 14 道集中在定量与平衡部分，尚不能当测评量表用。
4. **选择性必修第二、三册只到章级**（选必二 2 个、选必三 5 个），章内节（如「共价键」「分子的空间结构」「卤代烃」「醇 酚」）尚未拆点，是下一轮扩点的主要缺口。

# 化学（`chemistry`）

人教版化学，覆盖**九年级上册 / 下册**与**高中必修第一 / 二册、选择性必修第一 / 二 / 三册**，共 7 册。
按教材「单元—课题」（初中）／「章—节」（高中）两级建点，先修边沿教材顺序成链；每课时点 8 题、每单元点 5 题。

## 4. 试卷与讲解

- 卷制：初中 **120 分 / 120 分钟**（18 选择×3 ＋ 6 综合×11）；高中 **150 分 / 150 分钟**（18×3 ＋ 6×16）。
- 单元卷必须覆盖本章/单元全部知识点各 ≥1 次；期中卷取该册前一半单元（按单元号，不是字符串排序）、期末卷覆盖全册。
- 卷面**原创性**：与题库任一题干相似度 <0.85；单卷答案位 A–D 各 ≥15%（18 题各 ≥3）。
- 讲解六段：考什么 → 考点地图 → 逐题精讲（综合题按 `scoreRule` 分步给分）→ 整卷复盘 → 五步学习法 → 自查清单；24 题逐题覆盖。

## 6. 已知缺口（如实记录）

1. **初中学段只到「课题」**：人教版 2026 版教材目录以「课题」分节（每单元 2–3 个），没有把课题内的知识点（如「氧气的性质」「氧气的制法」）再拆；高中按「节」拆。跨学段比较粒度时注意口径。
2. **领域沿用义教 5 主题**：高中部分也用「物质的性质与应用 / 物质的化学变化 / 物质的组成与结构 / 化学与社会·跨学科实践 / 科学探究与化学实验」，没有改用高中课标模块名（化学1、化学反应原理…），与库内既有口径一致。
3. **选择题答案位全局偏斜**：A 117 / B 138 / C 70 / D 35（D 占 9.7%）。单卷闸门（每卷 A–D 各 ≥3）都过，但全库未做跨卷轮换。
4. **课标引文以「同单元借标」为主**：120 点里 99 点是借同单元/邻单元的课标原句（`confidence: partial`），21 点是原 id 恢复；义教课标对初中课题的逐条对应本就粗，未强求一一对应。
5. **难度与题干未经一线教师审读**：难度是命题时预估，未用学生作答数据校准。

## 9. 页面用法

- 学科下拉选「化学（人教版）」→ 初中学段按「九年级上册 / 下册」、高中按「必修一 / 必修二 / 选必一 / 选必二 / 选必三」分组。
- 学层页按册进入逐课时；整卷测试页按册选卷；讲解页从整卷页跳转。

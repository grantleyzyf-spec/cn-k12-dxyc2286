## 3. 课标对齐

- **依据**：义务教育阶段——《义务教育艺术课程课程标准（2022 年版）》（音乐为其中 5 个学科之一）；高中——《普通高中音乐课程标准（2017 年版 2020 年修订）》。
- **义教课标原件是扫描件**（PDF 131 页，无文字层）。本轮用 `PyMuPDF` 250 dpi 渲染 + `tesseract chi_sim` 逐页 OCR，产出快照
  `中小学教材/2025修订课程标准TXT /义务教育/《义务教育艺术课程标准》(2022年版) 扫描件OCR.txt`，`\f` 分页。
- **35 条 `quote` 全部逐字回表**，`sourceLine` 按新快照重算定位（去掉空白与标点后子串匹配，`scripts/test_music.py` 会重跑；CI 无 TXT 时自动跳过）。
- 义教部分 OCR 纠错 1 处（其余 25 条回表即命中）：

  | 位置 | OCR 读出 | 原文（人工核对页面图像确认） | 处理 |
  | --- | --- | --- | --- |
  | 义教艺术课标 p.38（学段二 音乐 内容要求） | 能用打击乐器或其他课**答/等**乐器…… | 能用打击乐器或其他课**堂**乐器…… | 回表前把 OCR 文本改回「堂」 |

- 条目 id 形如 `mus-2022:2.KC.10`、`mus-2017:G.XB.03`，为**本仓库自编**，不是教育部原编号：`2022` 后接**学段**（1 = 1–2 年级、2 = 3–5 年级、3 = 6–7 年级、4 = 8–9 年级，与艺术课标「四学段」划分一致），`KC` 唱奏与常识 / `TS` 唱游与表现任务 / `XY` 欣赏与体验；`2017` 后接 `NR`（必修模块内容要求）/ `XB`（选择性必修模块内容要求）/ `MB`（学科核心素养与基本理念）。
- `confidence` 分布：`exact` 24 · `partial` 11（`partial` 集中在「素养/理念段落 → 具体知识点」这一类映射，如「文化理解」素养段落对应 `mus_h004`）。

## 5. 本轮收口做了什么

1. **题库重建（24 → 38 题）**：原 24 题是模板题（题干「关于「X」，以下哪个说法正确？」，干扰项一律「与音乐表现无关 / 仅在大学学习 / 不属于音乐课程」），本轮按知识点内容逐题重写为情境化设问，干扰项改为同学段常见错误概念；新增 3 道数值题（3/4 拍拍数、五线谱线数、C 大调 I–IV–V 三和弦数）与 2 道简答题（悲伤情绪的音乐要素组合、变声期用嗓措施）；选项顺序轮转，答案分布 A 9 · B 8 · C 8 · D 8。
2. **难度三档**：原 24 题全部为 `easy`（别名，违反 v2 契约），本轮按认知层级定档（识记/模仿 → `basic`；辨析/综合运用 → `standard`；分析/创作/理论推理 → `hard`）→ `basic 10 / standard 21 / hard 7`。
3. **补 9 个高中模块知识点**：原高中仅 4 点（音乐鉴赏 / 歌唱 / 演奏 / 音乐与文化），课标必修 6 模块 + 选择性必修 6 模块大面积缺失。本轮按课标「内容要求」逐条取原文，补 `音乐编创`「音乐与舞蹈」「音乐与戏剧」（必修）与 `合唱`「合奏」「音乐基础理论」「视唱练耳」「舞蹈表演」「戏剧表演」（选择性必修），高中 12 个教学模块**全覆盖**。
4. **册次纠正 2 处**：`mus_h003` 演奏在课标中属**必修**模块（原误标「选择性必修」）；`mus_h004`「音乐与文化」不是课标模块名，按选修课程（学校自主开设）+「文化理解」核心素养定位，册名改「高中选修 音乐与文化」。
5. **根节点 `root_reason` 2 条**：`mus_p001`、`mus_p003` 同为一年级入学起点、互不为先修，理由写入节点。
6. **描述与掌握标准解耦**：原 24 点是「`description` = `mastery_criteria[0]`」照抄，本轮描述改写为**解释型**（为什么/是什么），掌握标准保留**可观察判据**；`scripts/test_music.py` 增加「描述不得照抄判据」不变量。
7. **领域纠偏**：`和声基础`、`调式与调性` 从「音乐表现」移到「音乐理论」（新增取值）；新增 9 点按课标归属挂 音乐表现 / 音乐创作 / 音乐理论。
8. **课标快照归档**：义教艺术课标扫描件 OCR 成 TXT 快照，高中音乐课标 `pdftotext` 快照存入同一 TXT 目录，`sourceLine` 全部按新快照重算。

## 6. 已知缺口（不编造，留档）

- **无教材逐册核对**：README 标注教材版本为人教版，但 `chapter` 第二段是本库内容领域标签，未与人教版各册单元号逐条对齐；义教「唱游·音乐 / 音乐 / 艺术选项」的学段口径来自艺术课标而非教材目录。
- **义教课标为 OCR 快照**：单字识别误差已人工核对纠正 1 处，其余 25 条回表命中；但 OCR 文本不能当作课标原文的权威电子版使用，正式引用仍应以 PDF 为准。
- **题量偏薄**：33 个知识点共 38 题，平均 1.15 题/点；低年级多为单点识记题，尚未形成「同点多难度梯度」。
- **高中节点无教材页码**：高中音乐模块以 18(或 36) 学时组织，本库按一个模块一个节点建点，未细分到「内容要求」下的每个条目（如音乐鉴赏 1.1–1.8 只合并为 1 个节点）。
- **选修课程无节点**：课标「选修课程」由学校自主开设、无统一模块名，本库不建点（`mus_h004` 为素养节点，非选修模块）。

## 7. 自检

```bash
python3 scripts/test_music.py        # 44 项不变量
python3 scripts/validate.py music    # 结构 / 引用
python3 scripts/validate.py --all    # 全学科
python3 scripts/build_standards_index.py   # 课标索引（CI 会做新鲜度 diff）
```

`scripts/test_music.py` 覆盖：id 形态与唯一性 / subject 一致 / 每点有题 / 课标 id 可解析 / 每条引用带 quote（12–40 字）/ confidence 三档 / **quote 逐字回表 + sourceLine 可定位**（缺 TXT 自动跳过）/ 边无自环无重复两端存在、hard-soft 枚举 / **deps ↔ prerequisites 双向镜像** / 先修图无环 / **先修边不指向更低年级** / 根节点 root_reason / 难度枚举合规且三档都用到 / 题型至少三类 / 选择题 4 选项且选项文本互不重复、答案在选项内 / 题干 ≥12 字 / 每题有解析 / prompt 与 question 同值 / numeric 带 verify 且 answer 与 verify 复算一致 / 非选择题不带 options / 核心字段齐全 / 掌握标准 1–3 条 / **描述不照抄判据** / **义教年级与艺术课标四学段一致** / 同学段内不重名 / 高中册名前缀合规 / **高中必修与选择性必修 6 模块全覆盖** / 义教册名可派生 / domain 取值在既定四类内。

## 8. 页面用法

- 知识图谱：`explore/?subject=music`，按「年级·册」分组；高中节点折叠在「高中必修」「高中选择性必修」「高中选修」三组下，点节点可看课标原文、样题、先修关系。
- 诊断：`diagnose/?subject=music`，沿 `hard` 边自适应出题，数值题按数值比对、简答题按关键词提示自评。
- 直接定位：`explore/?subject=music#mus_h010`（音乐基础理论）。

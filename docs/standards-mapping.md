# 课程标准对齐说明

本文档说明知识图谱与教育部课程标准的对齐方式。

## 对齐依据

### 义务教育阶段（1-9年级）

- **课程标准**：《义务教育数学课程标准（2022年版2025年修订）》
- **教材版本**：人教版（2024年审定新版）
- **学段划分**：
  - 第一学段：1-2年级
  - 第二学段：3-4年级
  - 第三学段：5-6年级
  - 第四学段：7-9年级

### 普通高中阶段（10-12年级）

- **课程标准**：《普通高中数学课程标准（2017年版2025年修订）》
- **教材版本**：人教A版（2019年审定）
- **课程结构**：
  - 必修课程：必修第一册、第二册
  - 选择性必修课程：选择性必修第一册、第二册、第三册

## 课标编号规则

本图谱自编课标编号，格式为 `cms-{年份}:{主题}.{子主题}.{条目}`

### 义务教育编号示例

| 编号 | 含义 |
|------|------|
| cms-2022:1.1.1 | 第一学段·数与运算·数的认识 第1条 |
| cms-2022:1.1.2 | 第一学段·数与运算·数的运算 第2条 |
| cms-2022:2.1.1 | 第二学段·图形与几何·图形的认识 第1条 |
| cms-2022:3.1.1 | 第三学段·代数思维·探索规律 第1条 |
| cms-2022:4.1.1 | 第四学段·综合与实践 第1条 |

### 高中编号示例

| 编号 | 含义 |
|------|------|
| cms-2017:H.PRE.01 | 高中·预备知识·集合 第1条 |
| cms-2017:H.FUN.01 | 高中·函数·函数概念 第1条 |
| cms-2017:H.GA.01 | 高中·几何与代数·平面向量 第1条 |
| cms-2017:H.PS.01 | 高中·概率与统计·统计 第1条 |
| cms-2017:H.MI.01 | 高中·数学建模·建模活动 第1条 |

| 学段 | 册次 | 课标条目数 |
|------|------|-----------|

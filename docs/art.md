# 美术 / 艺术（`art`）

美术按「数据 → 课标回表 → 题库 → 自检 → 文档 → 页面口径 → CI」七件套收口，口径与数学、语文、生物一致（见 [docs/math.md](math.md)、[docs/chinese.md](chinese.md)、[docs/biology.md](biology.md)）。

## 1. 规模

| 项目 | 数量 | 说明 |
| --- | ---: | --- |
| 知识点 | 26 | 小学 15（一–六年级）· 初中 6（七–九年级）· 高中 5（必修 / 选择性必修） |
| 先修边 | 26 | 全部 `hard`，两端均在知识点内，无自环、无重复、无环 |
| 诊断题 | 26 | 与知识点 1:1，全部为情境化选择题 |

## 3. 课标对齐

- **义务教育段**依据《义务教育艺术课程标准（2022 年版）》「（二）美术」部分；**高中段**依据《普通高中美术课程标准（2017 年版 2020 年修订）》。
- 条目 id 为**本仓库自编**，不是教育部原编号，但**编码位置可追溯**：`art-2022:{学段}.T{学习任务}.{条序}`，例如 `art-2022:2.T2.04` = 义务教育第二学段（3–5 年级）学习任务 2 的第 4 条内容要求；`art-2017:G.NR.03` = 高中美术课标内容要求第 3 条。
- **26 条 `quote` 全部逐字回表**（`scripts/test_art.py` 会重跑）。
- `confidence` 分布：`exact` 8 · `partial` 13 · `inferred` 5。
- 义务教育艺术课标官方 PDF 是**扫描版（131 页、无文字层）**，`2025修订课程标准TXT /义务教育/` 里也没有它的 TXT 快照，因此回表底本由 `scripts/ocr_art_standards.py` 现场 OCR 生成（`/tmp/art_yijiao_ocr.txt`）；高中美术课标 TXT 是 **GB18030 编码**，脚本转存为 UTF-8（`/tmp/gaozhong_meishu.txt`）。底本缺失时自检跳过回表（与 `test_physics.py` 同款约定，CI 不会红）。

**OCR 误识登记（4 处，`test_art.py` 的 `OCR_FIX`）**

| 条目 | OCR 读出 | 原文 | 处理 |
| --- | --- | --- | --- |
| `art-2022:1.T2.04` | 折、**和县**、揉、搓、压 | 折、**剪**、揉、搓、压 | 回表前把 OCR 文本改回「剪」 |
| `art-2022:2.T1.01` | 书法**繁刻** | 书法**篆刻** | 同上 |
| `art-2022:4.T1.04` | 运用线条**有**形状 / 形式原理**汰析** | 运用线条形状 / 形式原理**分析** | 同上 |
| `art-2022:4.T4.01` | 情况**感情**继承 | 情况**感悟**继承 | 同上 |

> 这些误识只存在于 OCR 底本，**数据里的 `quote` 用的是校订后的正确原文**；登记表就是「为什么底本与 quote 差一个字」的可复算凭据。

## 5. 本轮收口做了什么

1. **题库整体重建（最实质的修复）**：原 26 题是模板生成题——三个干扰项固定为「与 X 无关」「仅在大学学习」「不属于美术课程」，26 题**答案全是 A**，正确项文字还被截断成「……」。这类题在 `validate.py` 与四道闸门下全部合规，但属**语义废题**（学生一律选 A 即满分）。本轮改为 26 道情境化题干 + 真干扰项（每题的错项都对应一个具体误区，如「墨分五色」题把「油彩堆叠」写进错项），答案分布拉平为 A 5 / B 8 / C 7 / D 6，并把 `topics.diagnostic_question` 与新题同步。
2. **课标重挂（语义错配纠正）**：原 21 条义务教育条目按序号 1→21 顺排在 21 个知识点上，实际大量错配——「对称与均衡」挂的是「为班级设计标识、请柬」条，「泥塑基础」挂的是「制作定格动画」条，「素描基础（明暗）」挂的是「欣赏各民族建筑」条；且 `quote` 一律截断在逗号处（如「能根据周边环境中各种自然物与人造物，运用线条、形状」）。本轮按「学段 + 学习任务 + 内容要求原文」逐条重挂，`quote` 补成完整句子，条目编码位置可追溯（见 §3）。
3. **难度归一**：26 题原全部 `easy`（别名，不符合 v2 契约），按题干认知要求重分为 `basic 10 / standard 13 / hard 3`。
4. **知识点类型**：按高置信关键词细分，不再 17 个 `conceptual` 一统（技法类 → `procedural`，鉴赏类 → `application`）。
5. **领域校正**：高中「美术鉴赏方法论」「中国美术史」「西方美术史」原误挂 `造型表现`，改挂 `欣赏评述`。
6. **根节点**：3 个根节点补 `root_reason`。
7. **新增自检**：`scripts/test_art.py`（31 项不变量），其中 5 项是本学科专属的**质量闸门**——答案分布不单一、选项无占位/玩笑干扰项与截断省略号、`domain` 属四类艺术实践、年级 1–12 全覆盖、课标条目无孤儿。

复算命令：`python3 scripts/fix_art.py`（dry-run，`--write` 生效，幂等）。

## 6. 已知缺口（不编造，留档）

- **粒度偏粗**：26 个知识点覆盖 1–12 年级，平均每年级 2 个点；相比数学（479）、物理（177）密度很低。教材逐课拆解后可扩到 3–5 倍，本轮只做「同口径收口」，不虚增节点。
- **5 条 `inferred` 属学段偏移**：课标在对应学段没有该内容的明文，按最近条目推断挂靠——`art_p007` 泥塑基础（g3 ← 第一学段 1.T2.04）、`art_p008` 色彩冷暖（g3 ← 第三学段 3.T2.01）、`art_p014` 素描明暗（g6 ← 第四学段 4.T1.04「明暗」作为造型元素）、`art_p016` 速写 / `art_p017` 水彩技法（g7 ← 第四学段 4.T2.06）。义教课标对「素描 / 速写 / 水彩」不作单独技法表述，故记 `inferred` 而非 `exact`。
- **13 条 `partial`** 多为「欣赏语境」条目承载「造型/设计」知识点（如 `art_p001` 线条与形状 挂 1.T1.03 的欣赏评述条），或条目覆盖面大于知识点（如 `art_p012` 欣赏中国名画 挂「欣赏中外著名艺术家的美术作品」）。
- **题库全部为选择题**：没有填空与开放题；`application` 类知识点（鉴赏方法论、美术史）更适合承载「简答/评述」题，需另建题型与判分口径后再补。
- **`hard` 仅 3 题**：靠「明暗五层次」「作品—朝代对应」「鉴赏路径判定」承载多步判断，其余以识记理解为主。
- 高中 5 条仍用 `art-2017:G.NR/XY.*` 旧编号（与物理/生物同构），未改成 `T{模块}.{条序}` 式可追溯编码；如后续统一编码规则，需同步改 `curriculumRef`。

## 7. 自检

```bash
python3 scripts/ocr_art_standards.py   # 生成课标回表底本（扫描版 OCR + GB18030 转码），约 3–5 分钟
python3 scripts/test_art.py            # 31 项不变量，含 quote 逐字回表 26/26
python3 scripts/validate.py art        # 结构 / 引用校验
python3 scripts/validate.py --all      # 全库校验（Total Errors: 0）
```

## 8. 页面用法

- 学科页：`index.html?subject=art`
- 指定年级：`?subject=art&grade=4`
- 指定知识点：`index.html?subject=art#art_p009`
- 诊断页：`diagnose/?subject=art#art_p014`

`grade` 10–12 在页面上显示为册名（高中必修 / 选择性必修），不显示「十/十一/十二年级」。

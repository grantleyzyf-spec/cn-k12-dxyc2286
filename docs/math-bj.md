## 3. 层级与结构口径

- **单元点**（`level: unit`）：教材的「单元 / 章」，名称与教材目录一致；小学一至三年级写「第N单元」，四至六年级教材用「一、二、…」、入库统一为「第N单元」；初中为连续章号（七上 1–3、七下 4–9、八上 10–13、八下 14–17、九上 18–21）。
- **课时点**（`level: lesson`）：小学取大单元教学设计「十五、教-学-评一致性课时设计」的「第N课时 X」；初中取教材目录的 `x.y` 节。
- `chapter` 形如 `一年级上册 第一单元 我是小学生 参观校园`（册 → 单元 → 课时）；页面册名从 `chapter` 派生，`grade` 只用于排序。
- 先修边四类：单元→其下各课时（hard）、课内课时顺次（hard）、册内前单元末课时→后单元（hard）、册际前册末课时→后册首单元（soft）。
- `domain` 按 2022 课标四领域：数与代数 385 / 图形与几何 111 / 统计与概率 54 / 综合与实践 76。
- `type`：conceptual 397 / procedural 129 / modeling 79 / reasoning 21。

## 6. 已知缺口

1. **缺 4 册教材**（四下、五下、六下、九下）：无 PDF，未建点。补书后：`_build/skeleton.py` 会按册序续排 id（**只增不改**，重排会让已有题目 `topicId` 全部失联）。
2. **139 个点无课标对应**（626 − 487）：低年级活动类（参观校园、我的新朋友、游戏分享、整理书包）、练习/复习课、数学百花园等，2022 课标为「学段 × 领域」粒度，无逐条条文；按「宁可留空、不编造」处理。
3. **挂标 confidence 以 partial 为主**：义教课标不细到单元，只能引同领域同学段条目，属正常口径。
4. **候选集 id 复用问题**：`mat-2022:*` 现有编号体系是人教版按知识点各自编号，同一编号可能对应多条不同引文，导致候选集折叠后部分表述失效（这也是挂标率停在 77.8% 的原因之一）。彻底修法是先把课标原文条目化重编 id（独立批次），不在写手端放宽引文校验。
5. **七下 6 章目录为扫描件**：章节名由 350–500 dpi 重 OCR 后人工核定（`_build/_overrides.json`），已与大单元教学设计逐章核对。

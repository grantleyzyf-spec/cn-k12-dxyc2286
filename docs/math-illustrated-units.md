# 两个「插图标题」单元的课时名核定记录

有两个单元的课时标题在教材里是**插图**（PDF 文字层抽不出来），因此建课时点时被整体跳过，
对应单元一直只有单元级点、也出不了单元卷。2026-11-01 翻图读名，逐页核定如下。

## 一、一年级上册 第三单元「认识立体图形」

- 教材文件：`中小学教材/数学/小学/人教版/义务教育教科书 数学 一年级 上册.pdf`
- 印刷页 → PDF 索引：**−4**（印刷 68 = 索引 72）
- 单元范围：印刷页 67–72（目录页可见「三 认识立体图形 67」，第四单元从 73 起）

| 课时名 | 印刷页 | PDF 索引 | 页面上读到的原文 |
|---|---|---|---|
| 按形状分一分 | 68 | 72 | 「1 按形状分一分。」＋「你发现了什么？」「说一说你身边哪些物品是这些形状的。」页脚「68 认识立体图形」 |
| 搭积木 | 70 | 74 | 「2 所有的积木都要用上，看谁搭得又稳又高。」＋阅读理解/分析解答/回顾反思；页脚「70 认识立体图形」 |
| 拼一拼 | 71 | 75 | 「3 拼一拼。」＋做一做（4 个相同小长方体拼出不同长方体）；页脚「71」 |

插页说明：69 页是「做一做（我说你拿／我说你猜／我说你搭）」，72 页是练习（连一连／数一数／接下来应该摆什么），均不单独成点。

## 三、复核方式（可复算）

```bash
# 渲染指定页供目视
python3 - <<'PY'
import fitz
p="…/义务教育教科书 数学 一年级 上册.pdf"
d=fitz.open(p); d[72].get_pixmap(dpi=130).save("/tmp/p68.png")
PY
```

判据：每页的**课时编号（1/2/3）**必须在页面正文区可见，且**页脚页码**与印刷页一致；
两条都对上，才算「翻图读名」成功。只凭正文里出现某词就定课时名不算数。

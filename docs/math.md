## 3. 课标对齐

- 依据：《义务教育数学课程标准（2022 年版 2025 年修订）》＋《普通高中数学课程标准（2017 年版 2020 年修订 / 2025 年日常修订）》的本地 TXT 快照。
- **601 条 `quote` 全部通过逐字回表**：把课标 TXT 去空白后做子串匹配，命中 **601 / 601**（`scripts/test_math.py` 会重跑这一步）。
- `confidence` 分布：`exact` 325 · `partial` 234 · `inferred` 42。
- 条目 id 形如 `mat-2022:4.XY.21`、`mat-2017:G.NR.03`，是**本仓库自编**，不是教育部原编号。

## 4. 题库与题型

| 维度 | 分布 |
| --- | --- |
| 题型 | 选择题 472 · 数值题 6 · 填空 1 |
| 难度 | `basic` 90 · `standard` 386 · `hard` 3 |
| 知识点类型 | `conceptual` 430 · `procedural` 45 · `reasoning` 4 |
| 校验式 | 6 道数值题全部带可复算 `verify`（如 `9+4`） |

选择题一律 4 个 `{label, text}`，`answer` 必须是 label；「>、<、=」这类只有三个自然选项的题，已改为填空题，不再套选择题壳子。

## 5. 已知缺口（如实记录，不编造）

1. **`mat_p215 数学广角——搭配(一)`、`mat_p348 鸽巢问题`**：教材有内容，但 2022 版义教课标没有逐条对应表述（课标把这类内容归在「综合与实践」的活动建议里），因此 `standards: []` 留空。
2. **`mat_p924 圆和圆的位置关系`**：2022 版义教课标未单列该条；高中选必「平面解析几何」有「判断直线与圆、圆与圆的位置关系」的表述，但学段不同，**不跨学段挂**。
3. **`inferred` 42 条**：多为教材有、课标只给上位表述的知识点，标注为推断而非直引。
4. **难度标签未经学生数据校准**，`hard` 仅 3 道，说明题库整体偏基础，不能当测评用。

## 6. 自检与校验

```bash
cd cn-k12-dxyc2286
python3 scripts/test_math.py          # 25 项不变量（唯一性/册次/课标/回表/边/题/字段）
python3 scripts/validate.py math      # 单学科结构校验（CI 同款）
python3 scripts/build_standards_index.py   # 重建课标索引（改数据后必跑）
python3 scripts/build_stats.py --write     # 刷新统计（README / 首页数字）
```

`test_math.py` 覆盖：知识点 479 条且 id 唯一、年级覆盖 1–14、带课标比例、课标 id 可解析、每条带 `quote` 且回表命中、`confidence` 三档、先修边无自环/无重复/两端存在/与 `prerequisites` 双向镜像/无环、根节点有 `root_reason`、每题可用（4 选项、答案在选项内、题干 ≥8 字、有解析、数值题有 `verify`）、核心字段齐全、掌握标准 1–3 条。

## 7. 页面怎么用

- 首页点「数学」→ `explore/?subject=math`，默认落在关系最密的知识点（当前是「有理数的混合运算」），可用搜索、层级、点节点换中心。
- 诊断：`diagnose/?subject=math`，选学科与目标知识点后沿 hard 边回溯出题。
- 学习档案按孩子记录诊断结果（`localStorage`，不出本机）。

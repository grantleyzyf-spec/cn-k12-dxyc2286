五年级上册 小数乘法

数学人教版五年级上册更新：2026-10-31

单元内容概览

本单元是小学数学数与运算领域的重要单元，围绕「小数乘法」组织教学内容，引导学生把整数乘法的计算方法与运算规律迁移到小数中来。单元从买风筝、试验田面积等生活情境入手，先教学小数乘整数，借助乘数和积的变化规律把小数乘整数转化为整数乘法再确定小数点；接着教学小数乘小数，理解按整数乘法算出积后再根据乘数中小数的位数确定积的小数点数位；随后学习积的近似数，掌握用「四舍五入」法求积的近似值；进而把整数乘法的交换律、结合律和分配律推广到小数，学会运用运算律进行简便计算；随后运用小数乘法解决购物估算、出租车分段计费等实际问题。

单元学习目标

  1. 通过本单元学习，学生能用数学的眼光观察现实世界，能从购物结算、试验田面积、出租车计费、水费、用电等生活情境中识别出小数乘法的数量关系，看到单价乘以数量、一个数的小数倍、分段累加等问题的本质。学生能分清情境中谁是已知量、谁是所求量，能把「买 0.8 m 彩带要花多少元」「花生产量是五（1）班的 0.8 倍是多少千克」等描述正确转化为小数乘法算式，体会小数乘法在…
  2. 通过本单元学习，学生能用数学的思维思考现实世界，理解小数乘法的算理，能依据乘数和积的变化规律说明为什么可以把小数乘法转化为整数乘法计算，能解释积的小数位数与乘数中小数位数之间的关系，能说明积的末尾补 0 化简的道理。学生能归纳一个数乘大于 1 的数积比原数大、乘小于 1 的数积比原数小的规律，能把整数乘法的运算律推广到小数并用于简便计算，能根据实际需要选择精…
  3. 通过本单元学习，学生能用数学的语言表达现实世界，会正确使用乘数、积、积的近似数、四舍五入、运算律、简便计算、分段计费等术语，能完整说出小数乘法的计算方法与理由，能讲清估算时为什么总价既不超过 89 元又不低于 80 元。学生能熟练写出小数乘法算式，用「单价乘数量等于总价」「一个数的几倍用乘法计算」等数量关系式表达实际问题，能用线段图直观表示倍比关系、用列表整…
  4. 通过本单元学习，学生经历把旧知迁移到新情境、从特例归纳法则、应用运算律优化计算的完整过程，在动手算一算、比一比、验一验中积累丰富的运算活动经验。学生在用小数乘法解决购物、乘车、节能、大桥长度等真实问题时，体会数学与生活的密切联系，感悟数学的价值，萌生学好用好小数的兴趣与信心。学生通过与同桌讨论估算策略、互相验算、交流简便方法，养成合作交流、虚心倾听的学习品质…

教学重点

  • 掌握小数的乘法法则，正确确定积的小数点数位。
  • 理解整数乘法运算律推广到小数，能简便计算。
  • 会用估算、分段计费解决小数乘法的实际问题。

教学难点

  • 理解小数乘整数的转化算理，突破小数点定位的难点。
  • 积的小数位数不够时，会按需用0补足位数再点小数点。
  • 灵活选择精确计算或估算，正确理解分段计费的问题。

课时安排（6 课时）

  1. 第一课时　小数乘整数
  2. 第二课时　深化小数乘整数并认识一个数乘大于 1 或小于 1
  3. 第三课时　小数乘小数
  4. 第四课时　处理小数位数不够的补 0 情形
  5. 第五课时　学习运算律推广与简便计算
  6. 第六课时　运用估算与分段计费解决实际问题并整理复习

教学过程（节选）

学习目标：结合买风筝等具体情境理解小数乘整数的算理，能把 9.5×3、0.72×60 等按乘数和积的变化规律转化为整数乘法计算，掌握先算积、再确定积的小数点位的方法，并会化简积末尾的 0。

评价任务：独立算出 9.5×3 和 0.72×60 并讲清算理；说一说积的小数位数与乘数有什么关系；正确完成做一做、练习中的基础口算与笔算并估算检验。

学习活动：以「买 3 个风筝需要多少钱」引入，先让学生自主尝试，交流把 9.5 元看作 95 角、看作 9 元 5 角相加等多种算法，明确 9.5×3 可以转化为 95×3 再缩小十倍；再由学生算 0.72×60，比较乘数扩大或缩小与积变化的关系，发现 0.72 是 72 个 0.01、积就是 4320 个 0.01，得出 43.2，理解小数末尾 0 可化简及小数点位置的确定；随后算 0.7×4、1.24×15 等巩固定位。

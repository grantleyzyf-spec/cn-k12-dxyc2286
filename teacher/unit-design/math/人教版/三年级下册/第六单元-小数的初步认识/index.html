三年级下册 小数的初步认识

数学人教版三年级下册更新：2026-10-31

单元内容概览

本单元是人民教育出版社义务教育教科书数学三年级下册第六单元，内容为小数的初步认识，是数与代数领域的核心内容。学生在之前的学习中认识了整数和分数，本单元初步认识小数，理解小数的含义，掌握小数的读写，比较小数的大小，进行简单的小数加减计算。小数是数概念的重要组成部分，从整数、分数到小数是数概念的又一次扩展，本单元的学习为后续系统学习小数奠定基础。

单元学习目标

  1. 本单元学生能够结合具体情境，认识小数，理解像3.45、0.85、2.60和36.6这样的数叫作小数；能够用数学的眼光观察生活中的小数现象，发现价格、体温、身高中的小数，数感进一步发展，学会用数学的眼光观察周围世界中的小数。
  2. 本单元学生能够理解小数的意义，1分米是十分之一米也可以写成小数0.1米，3分米是3个0.1米，1厘米是百分之一米写成小数是0.01米；能够掌握小数的读写，3.45读作三点四五；能够掌握比较小数大小的方法，都化成厘米来比较；能够进行简单的小数加减计算，15角加38角等于53角，53角等于5.3元，列竖式计算时小数点要对齐；能够理解小数加减法和整数加减法类似都要…
  3. 本单元学生能够说一说小数的意义，用数学语言描述1分米是十分之一米也可以写成小数0.1米；能够读一读写一写小数，用数学语言表达小数；能够说一说比较小数大小的方法，用数学语言表达都化成厘米来比较；能够说一说计算的过程，用数学语言表达小数的计算；能够说一说生活中的小数，用数学语言表达价格、体温、身高中的小数；能够与同伴交流自己的发现，逐步学会用数学的语言表达现实世…
  4. 通过本单元的学习，学生不仅认识小数，更在丰富的观察和体验活动中获得积极的数学学习体验，感受数概念的扩展和数学与生活的密切联系，体验数学学习的乐趣；学生养成认真观察、规范书写、仔细计算的良好学习习惯，形成初步的数感，为后续的数学学习奠定基础，实现数学核心素养的整体发展。
  5. 目标叙写遵循可操作、可检测的原则。会用数学的眼光观察现实世界目标可以通过找一找、说一说等任务检测，学生能发现生活中的小数、说出小数的意义即为达标；会用数学的思维思考现实世界目标可以通过比一比、算一算等任务检测，学生能比较小数大小、计算小数加减法即为达标；会用数学的语言表达现实世界目标可以通过读一读、写一写等任务检测，学生能读小数、写小数、说算理即为达标。教师…

教学重点

  • 认识小数，理解小数的意义，掌握小数的读写。
  • 掌握比较小数大小的方法，进行简单的小数加减计算。
  • 解决与小数的加减有关的实际问题，整理本单元知识。

教学难点

  • 正确理解十分之几和百分之几与小数的关系，正确读写小数。
  • 正确比较小数大小，正确计算小数加减法，小数点对齐。
  • 正确解决与小数的加减有关的实际问题。

课时安排（7 课时）

  1. 第一课时　认识小数
  2. 第二课时　十分之几与小数
  3. 第三课时　百分之几与小数
  4. 第四课时　小数的大小比较
  5. 第五课时　简单的小数加、减法
  6. 第六课时　综合练习
  7. 第七课时　整理和复习

教学过程（节选）

学习目标：学生能够认识小数，理解像3.45、0.85、2.60和36.6这样的数叫作小数，掌握小数的读写。 评价任务：读出小数，写出生活中的小数。 学习活动：认识小数，我们以前学过的数像0、1、2、3、4这样的数是整数，像二分之一、四分之三、十分之一这样的数是分数，下面这样的数你见过吗，像3.45、0.85、2.60和36.6这样的数叫作小数；认识小数点，3.45读作三点四五，小数中间的圆点叫作小数点；找一找生活中的小数，你还在哪里见过小数写一写，0.85元每支、2.60元每支、36.6摄氏度体温正常、3.45千克；完成做一做，读出下面的小数，看图写出合适的小数。 一致性映射：认识小数对应理解小数概念目标，读写小数对应掌握小数读写目标。 板书设计：小数的认识和读写。

分层作业：必做小数读写练习，选做找生活中的小数写一写。

学习目标：学生能够理解十分之几可以写成一位小数，掌握1分米等于0.1米。 评价任务：把1分米、3分米用分数和小数表示，说出小华的身高。 学习活动：观察情境，小华身高1米3分米只用米作单位怎样表示；理解小数的意义，把1米平均分成10份每份是1分米，1分米是十分之一米也可以写成小数0.1米；理解3分米，3分米是3个1分米就是3个0.1米，3分米是十分之三米也可以写成0.3米；理解带单位的小数，1米3分米写成小数是1.3米；解决动物园购票问题，身高1.2米以下免票、超过1.2米且不足1.5米买儿童票，我身高1米3分米需要买儿童票；想一想，5分米等于多少米，1米7分米写成小数是多少米；完成做一做。 一致性映射：理解0.1米对应理解十分之几与小数关系目标，解决问题对应应用小数知识目标。

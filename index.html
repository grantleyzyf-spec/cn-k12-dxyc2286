先找到真正没学会的那一步

沿先修关系自适应出题：从你选的知识点往回追，逐层检测前置知识，定位薄弱根因， 再给出一条按学习顺序排好的路径。每个节点带可观察的掌握标准、诊断题和课标条目， 先修边分 hard / soft 两档。

开始诊断 浏览知识图谱

数据与页面均开源 · 纯静态、无外网 CDN · 学习档案只存本机

三步 选一个点，答几道题，拿到路径

  1. 选知识点或整册

    按学科、学段、年级筛选；也可以直接对一册做整册筛查。不知道选哪个，就先到「知识图谱」里搜关键词。

  2. 沿先修关系答题

    答对往下走，答错就沿 hard 先修边回溯到更低层；每个知识点最多问 2 题，逐层收窄范围。

  3. 拿到根因和路径

    结果分成「薄弱根因 / 不稳 / 未测」和按学习顺序排好的路径，可导出 JSON、可打印，也能存进孩子档案。

这个仓库有什么不同

掌握标准可判断

每个知识点给 1–3 条可观察的 mastery_criteria，不写「理解」「了解」这类空话。

先修边分强度

hard 表示不掌握前者基本学不会后者，soft 多为教材编排顺序；诊断只沿 hard 边回溯。

课标引文可复核

带 quote 的条目可用脚本回表核验「这段文字是否逐字出现在课标原文里」，避免编造。

17 个学科同一套契约

数学、语文、英语到德语、法语、西班牙语共用节点契约 v2，跨学科可比较、可合并。

纯静态、无外网依赖

页面只 fetch 仓库里的 JSON，图形库本地打包，不从 CDN 加载脚本、样式或字体。

档案存本机

孩子的诊断记录写在浏览器 localStorage，不上传、不联网，换设备不同步。

常见问题

这套先修关系能直接用于教学吗？

不建议。它是 AI 初稿：知识点粒度、hard / soft 判定、题目难度都没有经过教师评审，也没有学生答题数据校准。请当作「待审的草图」，先由一线教师审边、审题。

为什么有的学科没有课标引文？

引文要求逐字出自课标原文，做不到就不写。语文、历史、德语、俄语、法语、日语、西班牙语已完成引文回填；数学、英语、物理、生物、地理、化学、信息科技、美术、音乐、科学目前仍是课标编号引用，正在补。

小语种的义教段为什么没有课标？

义务教育阶段的外语课标只有英语、日语、俄语。法语、德语、西班牙语在 7–9 年级没有对应条文，只能挂高中课标并标 confidence: inferred。

怎么本地跑起来？

仓库根目录执行 python3 -m http.server 8000，再打开 http://localhost:8000/。页面用 fetch 读数据，不能直接双击 HTML 文件打开。

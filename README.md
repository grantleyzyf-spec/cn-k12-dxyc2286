# 中国 K-12 全学科知识图谱（cn-k12-dxyc2286）

对齐中国教育部课程标准的**全学科知识图谱开源数据库**，覆盖小学到高中 17 个学科。

## ⚠️ 状态声明

**这是 AI 生成的初稿，未经教师审核。** 知识点的拆分粒度、掌握标准、诊断题答案，尤其是**先修关系**都需要一线教师审核后才能用于教学、诊断或学习路径推荐。请勿直接用于正式教学。

## 数据结构

```
data/
├── {subject}/
│   ├── topics.json          # 知识点列表
│   ├── dependencies.json    # 先修关系
│   ├── curriculum.json      # 课标对齐
│   └── questions.json       # 诊断题库
```

### topics.json 格式

```json
{
  "id": "cnm_p001",
  "name": "20以内的进位加法",
  "subject": "math",
  "grade": 1,
  "semester": "fall",
  "chapter": "一年级上册 第五单元 20以内的进位加法",
  "description": "掌握凑十法，能正确计算20以内的进位加法",
  "tags": ["数与运算", "加法"],
  "prerequisites": ["cnm_p000"],
  "curriculumRef": "cms-2022:1.1.1"
}
```

### dependencies.json 格式

```json
{
  "from": "cnm_p001",
  "to": "cnm_p010",
  "type": "hard"
}
```

- `hard`：必须先掌握才能学习后续知识点
- `soft`：建议先掌握，但不是必须
